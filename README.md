# Mura GIS

Тарих және мәдениет ескерткіштерінің **қорғау аймағын**, **құрылыс салуды реттеу аймағын** және **қорғалатын табиғи ландшафт аймағын** есептейтін жұмыс үстелі бағдарламасы (Windows).

Есептеу ҚР Мәдениет және спорт министрінің 2020 жылғы 14 сәуірдегі № 86 бұйрығымен бекітілген қағидалардың 7–9-тармақтарына сәйкес жүргізіледі.

## Жоба мәртебесі

Mura GIS — **дербес жоба**. Ол бастапқыда aktobenasledie.kz сайтының әкімші панеліндегі «Қорғау аймағы» құралының жұмыс үстелі нұсқасы ретінде пайда болған, бірақ қазір сол жобадан толық бөлініп шықты:

- бағдарламаның бүкіл коды — осы репозиторийде, ол осы жерде дамиды және түзетіледі;
- сайтпен ешқандай байланыс жоқ: сайттан код көшірілмейді, сайттың серверіне, деректеріне не карта тайлдарына жүгінбейді;
- карта қабаттары тек ашық сыртқы сервистерден жүктеледі, сақталған аймақтар — тек пайдаланушының компьютерінде.

Әзірлеуші және жариялаушы: [BERIKKKK](https://github.com/BERIKKKK).

## Мүмкіндіктері

- **Ескерткіш шекарасы**: картада нүктелермен белгілеу (кемінде 4 нүкте), координаттарды кез келген пішімде енгізу (ондық градус, ° ′ ″, Excel-ден тізіммен), азимут пен қашықтық бойынша қосу, дәл өлшемді тіктөртбұрыш, GeoJSON файлынан жүктеу.
- **Үш аймақты автоматты есептеу**: ескерткіш түрі мен биіктігіне қарай қағидадағы қашықтық өздігінен қойылады (қолмен өзгертуге болады), аймақ шекаралары мен аудандары (га) шығарылады. Тым ойыс шекара үшін аймақ дөңес қабықшадан есептеліп, бұл туралы ескерту беріледі.
- **Өлшеу құралдары**: сызғыш (сызықтарға магниттеледі, перпендикуляр), бұрышты туралау.
- **Карта қабаттары** (сыртқы сервистер): OpenStreetMap, OpenTopoMap, Esri World Topo, КСРО Генштабы топокарталары (nakarte.me: AtloMaps мозаикасы және 1:1 000 000), Esri спутник; үстіңгі қабаттар (атаулар, жолдар). «Карта қабаттары → Сыртқы карта қосу» арқылы кез келген XYZ тайл-сервисін (QGIS «XYZ Tiles» пішімі) қосуға болады.
- **Экспорт**: GeoJSON, сызба (PNG), сызбасы бар Word (DOCX) құжаты; бірнеше аймақты бір DOCX-ке және QGIS стилі бар GeoJSON-ға біріктіру.
- **Сақтау**: аймақтар компьютердің өзінде сақталады; бағдарлама интернетсіз де жұмыс істейді (тек карта тайлдарына интернет керек).

### Қорғау аймағының қашықтығы (7-тармақ)

| Ескерткіш түрі | Қорғау аймағының ені |
|---|---|
| Биіктігі 40 м-ге дейінгі нысан (сәулет, монументтік өнер, киелі нысан) | биіктігінің 2 еселенген шамасы |
| Биіктігі 40 м-ден асатын нысан | биіктігінің 1 шамасы |
| Археологиялық ескерткіш | мәдени қабаттың шеткі шекарасынан 40 м |
| Ансамбль, кешен | шеткі нысанның шекарасынан 20 м |
| Қолданыстағы сәулет ортасындағы ескерткіш | қашықтықтар қолмен енгізіледі |

Әр жағдайда бағдарлама қолданылған тармақшаның мәтінін көрсетеді; ол DOCX құжатына да енеді.

## Деректер қайда сақталады

`%APPDATA%\Mura GIS\data\qorgau.json` (мәзір: **Файл → Деректер қалтасын ашу**). Әр сақтаудан кейін алдыңғы күйі `qorgau.json.bak` болып қалады.

Басқа компьютерге көшіру: **Файл → Сақталған аймақтарды файлға экспорттау / файлдан импорттау**.

Бағдарлама интернетке тек мыналар үшін шығады: карта тайлдары (жоғарыда аталған сервистер) және жаңартуларды тексеру (GitHub Releases). Пайдаланушының деректері ешқайда жіберілмейді.

## Әзірлеушілерге

Талаптар: Node.js 20+ және npm.

```bash
npm install
npm start         # бағдарламаны іске қосу
npm run smoke     # түтін тесті: есептеу, карта қабаттары, DOCX, сақтау
npm run dist:win  # Windows орнатқышы мен portable нұсқасы → dist/
npm run icon      # src/img/icon.svg → build/icon.png, src/img/icon.png
```

### Құрылымы

| Жол | Мазмұны |
|---|---|
| `main/main.js` | Electron негізгі процесі: терезе, мәзір, `mura://app/` протоколы, тайл сервистері үшін User-Agent |
| `main/store.js` | Сақталған аймақтар (`qorgau.json`), экспорт/импорт, `mura://app/api` |
| `main/updates.js` | GitHub Releases арқылы жаңарту (`electron-updater`) |
| `main/preload.js` | Интерфейске нұсқа нөмірін беру |
| `src/index.html` | Бағдарлама интерфейсі |
| `src/qorgau/app.js` | Негізгі логика: аймақтарды есептеу, координаттар, өлшеу құралдары, экспорт (GeoJSON, PNG, DOCX) |
| `src/qorgau/ui.js` | Құралдар жолағы мен панельдер |
| `src/js/basemaps.js` | Карта қабаттары және «Сыртқы карта қосу» |
| `src/js/desktop.js` | Жұмыс үстелі интерфейсі: күй жолағы, терезе атауы т.б. |
| `src/css/` | Стильдер |
| `src/vendor/` | Leaflet 1.9.4, fflate (DOCX/ZIP жасау үшін) |
| `scripts/smoke.js` | Түтін тесті |

Интерфейс файлдары `mura://app/` мекенжайымен беріледі (тұрақты origin — `localStorage`, `fetch` дұрыс жұмыс істейді). Сыртқы сілтемелер жүйенің браузерінде ашылады.

### Жаңа нұсқа шығару

1. `npm run smoke` — тест өтуі керек.
2. `package.json` → `version` өсіріңіз (мыс. `1.0.2`), commit жасаңыз.
3. `git tag v1.0.2 && git push origin main v1.0.2`
4. `GH_TOKEN` орнатып, `npm run release:win` — файлдар құрастырылып, [Releases](https://github.com/BERIKKKK/mura-gis/releases) бетіне жарияланады.

Орнатылған бағдарламалар жаңа нұсқаны өздері тауып, жүктейді.
