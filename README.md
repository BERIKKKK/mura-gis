# Mura GIS

Тарих және мәдениет ескерткіштерінің **қорғау аймағын**, **құрылыс салуды реттеу аймағын** және **қорғалатын табиғи ландшафт аймағын** есептейтін жұмыс үстелі бағдарламасы.

Есептеу ҚР Мәдениет және спорт министрінің 2020 жылғы 14 сәуірдегі № 86 бұйрығымен бекітілген қағидалардың 7–9-тармақтарына сәйкес жүргізіледі.

## Жүктеу

👉 **[Соңғы нұсқаны жүктеу](https://github.com/BERIKKKK/mura-gis/releases/latest)** · [Барлық нұсқалар](https://github.com/BERIKKKK/mura-gis/releases)

| Файл | Сипаттамасы |
|---|---|
| `MuraGIS-Setup-X.Y.Z.exe` | Windows орнатқышы. Жаңа нұсқалар **автоматты түрде** жүктеліп, орнатылады. |
| `MuraGIS-Portable-X.Y.Z.exe` | Орнатусыз іске қосылатын нұсқа (флешкадан да жұмыс істейді). Жаңартуды «Анықтама → Жаңартуларды тексеру» арқылы қолмен жүктейсіз. |

> Бағдарлама цифрлық қолтаңбасыз таратылады, сондықтан алғаш іске қосқанда Windows SmartScreen «Белгісіз баспагер» деп ескертуі мүмкін: **Толығырақ → Бәрібір іске қосу**.

Linux нұсқасы (AppImage, .deb) кейін шығады.

## Мүмкіндіктері

- Ескерткіш шекарасын картада нүктелермен белгілеу, координаттарды кез келген пішімде енгізу (ондық градус, ° ′ ″, Excel-ден тізіммен), азимут пен қашықтық бойынша қосу, дәл өлшемді тіктөртбұрыш.
- Үш аймақ шекарасын автоматты есептеу, аудандарын шығару.
- Өлшеу құралдары: сызғыш (сызықтарға магниттеледі, перпендикуляр), бұрышты туралау.
- Карта қабаттары: OpenStreetMap, спутник, тарихи топокарта (Генштаб СССР, Ақтөбе облысы).
- Экспорт: **GeoJSON**, **сызба (PNG)**, сызбасы бар **Word (DOCX)** құжаты; бірнеше аймақты бір DOCX-ке және QGIS стилі бар GeoJSON-ға біріктіру.
- Аймақтарды сақтау — компьютердің өзінде (интернетсіз де жұмыс істейді; карта тайлдары үшін интернет керек).

## Деректер қайда сақталады

`%APPDATA%\Mura GIS\data\qorgau.json` (мәзір: **Файл → Деректер қалтасын ашу**). Әр сақтаудан кейін алдыңғы күйі `qorgau.json.bak` болып қалады.
Басқа компьютерге көшіру: **Файл → Сақталған аймақтарды файлға экспорттау / файлдан импорттау**.

## Әзірлеушілерге

Құралдың бастапқы коды [aktobenasledie.kz](https://aktobenasledie.kz) сайтының әкімші панеліндегі «Қорғау аймағы» құралымен ортақ: `src/qorgau/`, `src/css/`, `src/js/basemaps.js` және `src/index.html` сайттан **автоматты көшіріледі** — оларды осы жерде қолмен өзгертпеңіз.

```bash
npm install
npm run sync      # сайт қалтасынан құралды көшіру (site.config.json → siteDir)
npm start         # бағдарламаны іске қосу
npm run smoke     # түтін тесті: есептеу, DOCX, сақтау
npm run dist:win  # Windows орнатқышы → dist/
```

Бағдарламаға ғана тән код: `main/` (Electron негізгі процесі, сақтау, жаңартулар), `src/css/desktop.css`, `src/js/desktop.js`.

### Жаңа нұсқа шығару

1. `npm run sync` (сайттағы құрал өзгерген болса), `npm run smoke`.
2. `package.json` → `version` өсіріңіз (мыс. `1.0.1`), commit жасаңыз.
3. `git tag v1.0.1 && git push origin main v1.0.1`

GitHub Actions Windows файлдарын құрастырып, [Releases](https://github.com/BERIKKKK/mura-gis/releases) бетіне жариялайды; орнатылған бағдарламалар жаңа нұсқаны өздері жүктейді.
