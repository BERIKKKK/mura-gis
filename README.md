# Mura GIS

**Тарихи-мәдени мұра объектілеріне арналған** ГАЖ жұмыс үстелі бағдарламасы: ескерткіштерді картада белгілеу және тізімдерін жасау, тарих және мәдениет ескерткіштерінің **қорғау аймағын**, **құрылыс салуды реттеу аймағын** және **қорғалатын табиғи ландшафт аймағын** есептеу.

Қолданылған нормативтік құқықтық актілер:
- ҚР «Тарихи-мәдени мұра объектілерін қорғау және пайдалану туралы» Заңы (2019 жылғы 26 желтоқсан, № 288-VI ҚРЗ) — ескерткіштердің түрлері (5-бап), санаттары (6-бап), мәртебесі (3–5-баптар): [adilet.zan.kz](https://adilet.zan.kz/kaz/docs/Z1900000288);
- ҚР Мәдениет және спорт министрінің 2020 жылғы 14 сәуірдегі № 86 бұйрығы — аймақтар шекаралары (7–9-тармақтар);
- ескерткіштер тізімі кестесінің үлгісі — облыс әкімдігінің жергілікті маңызы бар тарих және мәдениет ескерткіштерінің мемлекеттік тізімін бекіту туралы қаулысына қосымша (мыс. Түркістан облысы әкімдігінің 2020 ж. 17 қыркүйектегі № 188 қаулысы: [adilet.zan.kz](https://adilet.zan.kz/kaz/docs/V20U0005804)).

## Мүмкіндіктері

- Ескерткіш шекарасын картада нүктелермен белгілеу, координаттарды кез келген пішімде енгізу (ондық градус, ° ′ ″, Excel-ден тізіммен), азимут пен қашықтық бойынша қосу, дәл өлшемді тіктөртбұрыш.
- Үш аймақ шекарасын автоматты есептеу, аудандарын шығару. Шекара дайын болғанда **Аяқтау** басылады (не 1-нүктені басып, шекара жабылады): мәліметтер терезесі ашылып, қорғау аймағы сол жерден сақталады (белгі қоюмен бірдей логика; жолақта бөлек «Сақтау» жоқ). Терезеде белгіленген ескерткішті таңдасаңыз, мәліметтер белгіден толтырылады; шекара ішінде белгі болса, ол өзі таңдалады. Белгілер панеліндегі «Қорғау аймағы» — сол белгіден жаңа аймақ бастайды. Сақталған жазбалар — «Қорғау аймақтары» панелінде.
- **Екі қатарлы құралдар жолағы.** Жоғарғы қатарда — қызметтер (**Ескерткіштер**, **Маршруттар**, **Қорғау аймағы**) және ортақ құралдар (сызғыш, бұрышты туралау, сыйғызу, толық экран); төменгі қатарда — таңдалған қызметтің батырмалары. Қызметтерді `1`, `2`, `3` пернелерімен де ауыстыруға болады, соңғы таңдалғаны есте сақталады; басқа қызметтің әрекеті басталса (мыс. оң жақ мәзірден), жолақ сол қызметке өзі ауысады. Сақталған аймақты өңдеу — «Қорғау аймақтары» тізіміндегі «Өңдеу»; әр ескерткіштің жеке экспорты (GeoJSON, Word, сызба PNG) — сол тізімдегі «Экспорт ▾», төменде — таңдалғандарды біріктіріп экспорттау.
- Тінтуірдің оң жақ батырмасы: картада — координатаны көшіру (ондық градус, ° ′ ″), алмасу буферіндегі координатаны қою (картадан көрсету), осы жерге белгі не шекара нүктесін қою; белгіде — координатасын көшіру, өңдеу, қорғау аймағы; мәтін өрістерінде — қию, көшіру, қою.
- **Бүкіл Қазақстан**: 17 облыс және 3 республикалық маңызы бар қала, олардың аудандары мен облыстық маңызы бар қалалары (ағымдағы атаулар). Соңғы таңдалған облыс есте сақталады — қорғау аймағына да, белгіге де әдепкі болады, қажет болса ауыстырылады.
- **Белгі қою** — ескерткіштерді картада нүктемен белгілеу (қорғау аймағынан бөлек функция): атауы, мерзімі, облыс/аудан, орналасқан жері, түрі (Заңның 5-бабы), санаты (6-бап), мәртебесі. Белгінің иконкасы — түріне қарай (QGIS-пен ортақ SVG шартты белгілер, `src/marks/symbols/`), түсі — санатына қарай: халықаралық — күлгін, республикалық — қызыл, жергілікті маңызы бар — қызғылт сары, анықталмаған — сұр. Нүктелерді **KML, KMZ, GPX** файлдарынан импорттауға болады: олар Белгілер панелінің «Импортталғандар» қойындысында тұрады, картадан көрінеді, ал «Сәйкестендіру» басып мәліметтерін толтырғанда ғана белгіге айналады. Белгілер **GeoJSON** (нүктелер) және ескерткіштер тізімі ретінде **Word (DOCX)** мен **PDF** кестесіне экспортталады — облыс әкімдігі қаулысына қосымшадағы «Мемлекеттік тізім» үлгісімен, қаулы мәтінінсіз, әр санат бөлек кестеде; санат, облыс, аудан және атау бойынша сұрыпталады, атаудағы рим цифрлары (латын да, кирилл де: IV / ІҮ → 4, V / Ү → 5) санмен салыстырылады.
- **Маршруттар** — далаға шығу жолдары: маршрутты картада сызу (нүкте ескерткішке, басқа маршруттың ұшына не сызығына жақын басылса — соған жабысады; Enter / екі рет басу — аяқтау, Backspace — болдырмау, Esc — бас тарту) не GPX, KML, KMZ, GeoJSON тректерін импорттау. Әр маршрутта: басы мен соңы (А → Б), көлік (жеңіл көлік, жол талғамайтын көлік, жаяу), маусым (жыл бойы / тек құрғақта), соңғы рет тексерілген күні, ескертпе. **Жол табу**: сақталған маршруттардан желі құрылады (маршруттардың ұштары, қиылыстары және 300 м-ден жақын өтетін ескерткіштер — тораптар), ең жылдам жол Дейкстра алгоритмімен ізделеді. Мысалы, «Ақтөбе → 1-ескерткіш» және «1-ескерткіш → 2-ескерткіш» маршруттары болса, «Ақтөбе → 2-ескерткіш» екеуін тізбектеп береді. Басы/соңы — ескерткіш, желідегі пункт не картадағы кез келген нүкте (желіге дейінгі түзу қашықтық бөлек көрсетіледі); көлік пен маусым сүзгісі ескеріледі. Нәтиже — бөліктері, ұзындығы, шамамен уақыты, GPX экспорты. Оң жақ мәзірде: «Осы жерден / жерге жол табу», ескерткіште — «Осы ескерткішке жол табу».
- Өлшеу құралдары: сызғыш (сызықтарға магниттеледі, перпендикуляр), бұрышты туралау.
- Карта қабаттары — сыртқы сервистерден: OpenStreetMap, OpenTopoMap, Esri World Topo, **КСРО Генштабы топокарталары** (nakarte.me: AtloMaps мозаикасы және 1:1 000 000), Esri спутник; үстіңгі қабаттар (атаулар, жолдар). «Карта қабаттары → Сыртқы карта қосу» арқылы кез келген XYZ тайл-сервисін (QGIS «XYZ Tiles» пішімі) қосуға болады.
- Экспорт: **GeoJSON**, **сызба (PNG)**, сызбасы бар **Word (DOCX)** құжаты; бірнеше аймақты бір DOCX-ке және QGIS стилі бар GeoJSON-ға біріктіру.
- Аймақтарды сақтау — компьютердің өзінде (интернетсіз де жұмыс істейді; карта тайлдары үшін интернет керек).

## Деректер қайда сақталады

`%APPDATA%\Mura GIS\data\qorgau.json` (қорғау аймақтары) және `marks.json` (ескерткіш белгілері), `routes.json` (маршруттар) (мәзір: **Файл → Деректер қалтасын ашу**). Әр сақтаудан кейін алдыңғы күйі `qorgau.json.bak` болып қалады.
Басқа компьютерге көшіру: **Файл → Сақталған аймақтарды файлға экспорттау / файлдан импорттау**.

## Әзірлеушілерге

Mura GIS — дербес бағдарлама, оның барлық коды осы репозиторийде. Бағдарлама ешбір сайтқа не серверге тәуелді емес: деректер компьютерде сақталады, карта қабаттары ашық сыртқы тайл-сервистерден жүктеледі (`src/js/basemaps.js`).

```bash
npm install
npm run vendor    # Leaflet-ті node_modules-тен src/vendor/ ішіне жаңарту (қажет болғанда)
npm start         # бағдарламаны іске қосу
npm run smoke     # түтін тесті: есептеу, DOCX, сақтау
npm run smoke:marks  # белгі қою: сұрыптау, режимдер, GeoJSON / DOCX / PDF
npm run smoke:routes # маршруттар: сызу, импорт, жол табу
npm run dist:win  # Windows орнатқышы → dist/
```

Код құрылымы:
- `main/` — Electron негізгі процесі: терезе, мәзір, сақтау (`store.js`), жаңартулар, PDF;
- `src/index.html` — басты бет; `src/css/` — стильдер (`base.css` — негізгі, `maptool.css` — карта интерфейсінің қабығы, `desktop.css` — жұмыс үстелі, `marks.css` — белгілер);
- `src/qorgau/` — «Қорғау аймағы» қызметі (есеп, сызба, DOCX/GeoJSON экспорты, интерфейс);
- `src/marks/` — «Ескерткіштер» қызметі; `src/routes/` — «Маршруттар» (`graph.js` — желі және жол іздеу, `tracks.js` — GPX/KML/GeoJSON); `src/js/` — қызметтер жолағы (`services.js`), карта қабаттары, оң жақ мәзір, жұмыс үстелі қабығы т.б.;
- `src/vendor/` — Leaflet, fflate (офлайн жұмыс үшін жергілікті көшірмелер).

### Жаңа нұсқа шығару

1. `npm test` және `npm run smoke` (қажет болса `smoke:marks`, `smoke:routes`).
2. `package.json` → `version` өсіріңіз (мыс. `1.2.1`), commit жасап, `main`-ге жіберіңіз.
3. Тег жіберіңіз: `git tag v1.2.1 && git push origin v1.2.1`

GitHub Actions (`.github/workflows/release.yml`) Windows-та құрастырады: тег пен `package.json` нұсқасы сәйкес екенін тексереді, маршрут желісінің тестін өткізеді, орнатқыш пен портативті нұсқаны [Releases](https://github.com/BERIKKKK/mura-gis/releases) бетіне жариялайды; орнатылған бағдарламалар жаңа нұсқаны өздері жүктейді. Тегті қайта жариялау керек болса — Actions → Release → **Run workflow** (тегті көрсетіп). Өз компьютерден шығару да бұрынғыдай жұмыс істейді: `npm run release:win` (`GH_TOKEN` керек).
