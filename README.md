# Mura GIS

**Тарихи-мәдени мұра объектілеріне арналған** ГАЖ жұмыс үстелі бағдарламасы: ескерткіштерді картада белгілеу және тізімдерін жасау, тарих және мәдениет ескерткіштерінің **қорғау аймағын**, **құрылыс салуды реттеу аймағын** және **қорғалатын табиғи ландшафт аймағын** есептеу.

Қолданылған нормативтік құқықтық актілер:
- ҚР «Тарихи-мәдени мұра объектілерін қорғау және пайдалану туралы» Заңы (2019 жылғы 26 желтоқсан, № 288-VI ҚРЗ) — ескерткіштердің түрлері (5-бап), санаттары (6-бап), мәртебесі (3–5-баптар): [adilet.zan.kz](https://adilet.zan.kz/kaz/docs/Z1900000288);
- ҚР Мәдениет және спорт министрінің 2020 жылғы 14 сәуірдегі № 86 бұйрығы — аймақтар шекаралары (7–9-тармақтар);
- ескерткіштер тізімі кестесінің үлгісі — облыс әкімдігінің жергілікті маңызы бар тарих және мәдениет ескерткіштерінің мемлекеттік тізімін бекіту туралы қаулысына қосымша (мыс. Түркістан облысы әкімдігінің 2020 ж. 17 қыркүйектегі № 188 қаулысы: [adilet.zan.kz](https://adilet.zan.kz/kaz/docs/V20U0005804)).

## Мүмкіндіктері

- **Жобалар (GeoPackage).** Бағдарлама ашылғанда — бастапқы терезе: **Жаңа жоба** (атауы, облыс, аудан), **соңғы жобалар** тізімі және **«Басқа жобаны ашу…»** (файл таңдау терезесі). Әр жоба — бір `.gpkg` файлы: ескерткіштер (`marks`, нүкте), өзге нысандар (`places`, нүкте), қорғау аймақтары (`zones`, полигон), маршруттар (`routes`, сызық), «Жоспар» нысандары (`plan_objects`, полигон не нүкте), баптаулары (`plans`) және жағдаят белгілері (`plan_features`, сызық не нүкте), импортталған нүктелер (`imports`) — WGS 84 (EPSG:4326) қабаттары, оларды QGIS-те де ашуға болады. Жобада облыс таңдалса, жаңа ескерткіштер мен қорғау аймақтарында «Облыс» өрісі өзі толып, бекітіледі, тек сол облыстың аудандары таңдалады; аудан да таңдалса — ол да автоматты қойылады. Өзгерту — **Файл → Баптаулар → Жоба** (`Ctrl+,`) не күй жолағындағы жоба атауын басу. Мәзір: Файл → Жаңа жоба (`Ctrl+N`), Жобаны ашу (`Ctrl+O`), Соңғы жобалар, Бастапқы терезе, Жобаны жабу.
- **Екі тіл: қазақша / орысша.** Интерфейс тілі орнатқышта таңдалады (орнатқыштың өзі де екі тілде), кейін — **Баптаулар → Тіл / Язык** (бастапқы терезеде де бар). Орысша терминдер — «Об охране и использовании объектов историко-культурного наследия» Заңы мен № 86 бұйрықтың ресми орысша мәтіні бойынша. **Деректер екі тілде** енгізіледі: ескерткіштің атауы, мерзімі, орналасқан жері, сипаттамасы, ескертпесі — әрқайсысына «ҚАЗ» және «РУС» өрісі (GeoPackage-те `name` / `name_ru` т.б. бағандар). **Құжаттар интерфейстен тәуелсіз** кез келген тілде шығады («Құжат тілі»): қорғау аймағының қосымшалары — орысшасы Ақтөбе облысы әкімдігінің 2024 ж. 19 наурыздағы № 66 қаулысы үлгісімен («Границы охранной зоны…», «в Каргалинском районе Актюбинской области»), ескерткіштер тізімі — орысшасы Түркістан облысы әкімдігінің № 188 қаулысы үлгісімен («№ п/н | Наименование памятника | Вид памятника | …»). Құжат тілінде өріс бос болса, екінші тілдегісі алынып, ескерту шығады. Тест: `npm run smoke:ru`; Windows орнатқышы: `npm run dist:win` (NSIS-ке қазақ тілі `build/nsis-lang/` қалтасынан қосылады).
- **Бөтен GeoPackage-тен импорт** (Файл → GeoPackage-тен импорттау, `Ctrl+I`; Mura GIS жобасы емес .gpkg ашылғанда да ұсынылады — файлдың өзі өзгермейді). Әр қабатқа мақсат таңдалады: ескерткіштер, ескерткіш аумағы (қорғау аймағы жазбасы), дайын қорғау / реттеу / ландшафт аймақтарының полигондары, маршруттар, импортталған нүктелер. Атрибуттар кестесі өрістерге автоматты сәйкестендіріледі (қазақша, орысша, ағылшынша баған атаулары); сәйкес келмесе — **«Сәйкестендіру»** батырмасы арқылы әр өріске бағанды таңдайсыз. Координаттар WGS 84-ке түрлендіріледі: UTM (EPSG:326xx), Пулково 1942 / Гаусс-Крюгер (EPSG:284xx), Web Mercator, WKT-дағы көлденең Меркатор.
- **Аймақтардың заңнамаға сәйкестігі.** Импортталған аймақ полигондары ішіндегі ескерткіш аумағымен байланыстырылып, № 86 бұйрықтың 7–9-тармақтарына сәйкестігі тексеріледі (ескерткіш шекарасынан қашықтығы, ескерткішті толық қамтуы). Сәйкес келмесе — ескерту және таңдау: **Қалдыру** (полигондар файлдағыдай сақталады, жазбада белгіленеді) не **Қайта есептеу** (аймақтар ескерткіш аумағынан заң бойынша есептеледі). Бұл таңдау кейін де «Қорғау аймақтары» тізімінде және жазбаны ашқанда қолжетімді.
- **Құралдар панелін баптау.** «Баптаулар → Құралдар панелі» (жолақтағы тісті доңғалақ): кез келген батырманы жасыру/көрсету, топ ішіндегі ретін өзгерту (↑ ↓), «тек иконкалар» режимі, әдепкі күйге қайтару. Бағдарлама ашылғанда ешбір құрал (мыс. «Нүкте қою») өзі қосылмайды — құралды пайдаланушы өзі таңдайды.
- Ескерткіш шекарасын картада нүктелермен белгілеу, координаттарды кез келген пішімде енгізу (ондық градус, ° ′ ″, Excel-ден тізіммен), азимут пен қашықтық бойынша қосу, дәл өлшемді тіктөртбұрыш.
- Үш аймақ шекарасын автоматты есептеу, аудандарын шығару. Әдепкі тәсіл — **Орталық үлгісі**: аймақтың әр нүктесі ескерткіштің бір бұрылыс нүктесінен солтүстікке бағытталған сегізбұрыш бағытымен (0°, 45°, 90° …) дәл берілген қашықтыққа жылжиды, тік бұрышты аумақтың (қорғанның) аймақтары тік бұрышты болып қалады; баламасы («Аймақ нүктелерін салу») — әр қабырға алдыңғы шекарадан дәл берілген қашықтықта. Нүктелер барлық шекарада сағат тілімен, батыс-солтүстік-батыстағы нүктеден бастап бірдей нөмірленеді (аймақтың k-нүктесі ескерткіштің k-нүктесінен шығады). DOCX-тегі координаттар кестесі — әр шекараға жеке, «Нүкте | Солтүстік ендік | Шығыс бойлық», WGS 84, 50°06'08,8704" түрінде. Шекара дайын болғанда **Аяқтау** басылады (не 1-нүктені басып, шекара жабылады): мәліметтер терезесі ашылып, қорғау аймағы сол жерден сақталады (белгі қоюмен бірдей логика; жолақта бөлек «Сақтау» жоқ). Терезеде белгіленген ескерткішті таңдасаңыз, мәліметтер белгіден толтырылады; шекара ішінде белгі болса, ол өзі таңдалады. Белгілер панеліндегі «Қорғау аймағы» — сол белгіден жаңа аймақ бастайды. Сақталған жазбалар — «Қорғау аймақтары» панелінде.
- **Екі қатарлы құралдар жолағы.** Жоғарғы қатарда — қызметтер (**Ескерткіштер**, **Маршруттар**, **Қорғау аймағы**, **Жоспар**) және ортақ құралдар (сызғыш, бұрышты туралау, сыйғызу, толық экран); төменгі қатарда — таңдалған қызметтің батырмалары. Қызметтерді `1`–`4` пернелерімен де ауыстыруға болады, соңғы таңдалғаны есте сақталады; басқа қызметтің әрекеті басталса (мыс. оң жақ мәзірден), жолақ сол қызметке өзі ауысады. Сақталған аймақты өңдеу — «Қорғау аймақтары» тізіміндегі «Өңдеу»; әр ескерткіштің жеке экспорты (GeoJSON, Word, сызба PNG) — сол тізімдегі «Экспорт ▾», төменде — таңдалғандарды біріктіріп экспорттау.
- Тінтуірдің оң жақ батырмасы: картада — координатаны көшіру (ондық градус, ° ′ ″), алмасу буферіндегі координатаны қою (картадан көрсету), осы жерге белгі не шекара нүктесін қою; белгіде — координатасын көшіру, өңдеу, қорғау аймағы; мәтін өрістерінде — қию, көшіру, қою.
- **Бүкіл Қазақстан**: 17 облыс және 3 республикалық маңызы бар қала, олардың аудандары мен облыстық маңызы бар қалалары (ағымдағы атаулар). Соңғы таңдалған облыс есте сақталады — қорғау аймағына да, белгіге де әдепкі болады, қажет болса ауыстырылады.
- **Белгі қою** — ескерткіштерді картада нүктемен белгілеу (қорғау аймағынан бөлек функция): атауы, мерзімі, облыс/аудан, орналасқан жері, түрі (Заңның 5-бабы), санаты (6-бап), мәртебесі. Белгінің иконкасы — түріне қарай (QGIS-пен ортақ SVG шартты белгілер, `src/marks/symbols/`), түсі — санатына қарай: халықаралық — күлгін, республикалық — қызыл, жергілікті маңызы бар — қызғылт сары, анықталмаған — сұр. Нүктелерді **KML, KMZ, GPX** файлдарынан импорттауға болады: олар Белгілер панелінің «Импортталғандар» қойындысында тұрады, картадан көрінеді, ал «Сәйкестендіру» басып мәліметтерін толтырғанда ғана белгіге айналады. Белгілер **GeoJSON** (нүктелер) және ескерткіштер тізімі ретінде **Word (DOCX)** мен **PDF** кестесіне экспортталады — облыс әкімдігі қаулысына қосымшадағы «Мемлекеттік тізім» үлгісімен, қаулы мәтінінсіз, әр санат бөлек кестеде; санат, облыс, аудан және атау бойынша сұрыпталады, атаудағы рим цифрлары (латын да, кирилл де: IV / ІҮ → 4, V / Ү → 5) санмен салыстырылады.
- **Өзге нысандар** — ескерткіш емес, бірақ далада бағдар болатын нысандар: елді мекен, қыстау, жайлау, күзеу, көктеу, тұрақ, құдық, бұлақ, басқа. Жасалуы — «Белгі қою» сияқты: картаны басқанда алдымен белгі түрі сұралады — **Ескерткіш белгісі** (өрістері өзгеріссіз) не **Өзге нысандар** (түрі, атауы — міндетті емес, координатасы). Ескерткіштерден бөлек сақталады (жобаның `places` қабаты): ескерткіштер тізіміне, құжаттарына, қорғау аймағына әсер етпейді. Тізімі — «Ескерткіштер» панеліндегі **«Өзге нысандар»** қойындысы (іздеу, түрі бойынша сүзгі, GeoJSON экспорты); маршрут құруда басы/соңы бола алады. KML, KMZ, GPX не бөтен GeoJSON импорттағанда **қайда импорттау керегі сұралады**: ескерткіштерге («Импортталғандар» → сәйкестендіру) не өзге нысандарға (бірден, таңдалған түрмен); импортталған нүктені кейін де «Өзге нысан ретінде» сақтауға болады. Пішімі Android нұсқасымен ортақ.
- **Маршруттар** — далаға шығу жолдары: маршрутты картада сызу (нүкте ескерткішке, басқа маршруттың ұшына не сызығына жақын басылса — соған жабысады; Enter / екі рет басу — аяқтау, Backspace — болдырмау, Esc — бас тарту) не GPX, KML, KMZ, GeoJSON тректерін импорттау. Әр маршрутта: басы мен соңы (А → Б), көлік (жеңіл көлік, жол талғамайтын көлік, жаяу), маусым (жыл бойы / тек құрғақта), соңғы рет тексерілген күні, ескертпе. **Жол табу**: сақталған маршруттардан желі құрылады (маршруттардың ұштары, қиылыстары және 300 м-ден жақын өтетін ескерткіштер — тораптар), ең жылдам жол Дейкстра алгоритмімен ізделеді. Мысалы, «Ақтөбе → 1-ескерткіш» және «1-ескерткіш → 2-ескерткіш» маршруттары болса, «Ақтөбе → 2-ескерткіш» екеуін тізбектеп береді. Басы/соңы — ескерткіш, желідегі пункт не картадағы кез келген нүкте (желіге дейінгі түзу қашықтық бөлек көрсетіледі); көлік пен маусым сүзгісі ескеріледі. Нәтиже — бөліктері, ұзындығы, шамамен уақыты, GPX экспорты. Оң жақ мәзірде: «Осы жерден / жерге жол табу», ескерткіште — «Осы ескерткішке жол табу».
- **Жоспар** — ескерткіштің құрамындағы нысандар (мыс. «Қарасу қорымының» №1, №2, №3 қорғандары): ескерткіш картада бір карточкамен қалады, ал әр қорғанның тірек нүктесі, контуры, биіктігі мен диаметрі «Жоспар» бөлімінде сақталады. Ескерткіш тізімнен не картадан таңдалады, не ескерткіш карточкасындағы **«Жоспарды ашу»** (оң жақ мәзірде де бар). **Нысан қосу**: нөмірі (ескерткіш ішінде бірегей), түрі, тірек нүктесі (картадан, қолмен не **«Ескерткіштің негізгі координатасын алу»** — көшіріледі, тексеріп түзетуге болады; ескерткіштің өз координатасы өзгермейді). **Контур**: шеңбер (диаметр), эллипс (үлкен/кіші ось, азимут) не еркін контур — өлшемді енгізу не картада **сызу**; сақталған контурды картада тұтқалармен **редакциялау**. Контурсыз нысан жалпы жоспарда нүкте мен нөмір болып шығады. **Елді мекенге бағыттауыш**: елді мекен «Өзге нысандардан» не картадан таңдалады, бастапқы нүкте — ескерткіштің негізгі координатасы не таңдалған қорған; бастапқы азимут пен геодезиялық қашықтық (WGS 84, Винсенти) есептеледі, атауы, азимуты, қашықтығы қарындаш арқылы қолмен түзетіледі («Автоматты мәнге қайтару» бар). **Алдын ала қарау және PDF** — «Салтақ-III қорымы» үлгісімен (әдепкі A4 тік; **қағаз өлшемі** таңдалады: A5, A4, A3, A2, A1, A0 — тік не жатық, не өз өлшемі 100–3000 мм; барлық бет сол өлшемде, масштаб 1:1 сақталады, үлкен қағазда автоматты масштаб ірілейді; рамка, сол жақ жоғарыда солтүстік көрсеткісі, оң жақ жоғарыда атауы, облыс, аудан, төменгі оң жақта сызықтық масштаб): жалпы жоспар (қорған белгісі: нөмір | биіктігі / диаметрі, мыс. 1 0,7/13), жеке жоспар (контур, Ø 18 м өлшем сызықтары, биіктігі, масштабы) не біріктірілген PDF. Масштаб автоматты (сыйғызатын ең ірісі) не қолмен; сыймаса — ұсынылады. Белгілерді алдын ала қарауда сүйреп жылжытуға болады. PDF — вектор, мәтіні ізделеді, қаріп енгізілген, масштабы 1:1 (басып шығарғанда «Нақты өлшем / 100%»); тілі — қазақша не орысша. **Қорым экспликациясы (2-кезең):** нысан түрлері — қорған, кесене, сағана там, қоршау, құлпытас (Ажигали бойынша типімен), қойтас, сандықтас, үштас, бестас; материалы — күйдірілген кірпіш, шикі кірпіш, табиғи тас (белгісіз — «—»); техникалық жай-күйі (паспорттағы 4 деңгей). Тіктөртбұрыш контур (ұзындығы, ені, азимуты) — енгізу не картада сызу. Жоспарда материал штрихпен (ГОСТ 2.306-68 қағидасымен), контурсыз нысан векторлық белгімен көрсетіледі; төменгі аймақта — сызбада бар түрлер мен материалдардың «Шартты белгілері» және нөмірлері жоспармен сәйкес **экспликация** (сыймаса — келесі беттерде, тақырып жолы қайталанады, жоспардың масштабы сақталады). Экспликацияны пайдаланушы баптайды: бағандар мен реті, ені, жол биіктігі, жазу өлшемі, қысқа атаулар, кестенің орны. Тек қорғандары бар жоспар 1-кезеңдегідей қалады. Сипаттамасы — [docs/PLAN-STAGE2.md](docs/PLAN-STAGE2.md). **Жағдаят белгілері (3-кезең):** «Жағдаят» мәзірінен картада салынады — сызықтар (асфальт жол, дала жолы, соқпақ, ЭБЖ, шарбақ, арық, өзен, жыра, горизонталь биіктік мәнімен, басқа сызық), аудандар (егістік, орман, бұта, батпақ, су айдыны, құм, басқа аудан — штрихымен, ортасында жазуы), нүктелік белгілер (жеке ағаш — қатарынан бірнешеуі, геодезиялық пункт, мұнара, басқа бағдар, биіктік белгісі) және еркін жазу (бұрышымен); жазуы екі тілде. «Өзге нысандарды» (құдық, бұлақ, қыстау т.б.) жоспарға сілтеме арқылы қосуға болады. **Файлдан импорттау:** GeoJSON, KML, KMZ, GPX, DXF (AutoCAD, тахеометр — қабаттары белгі түрлеріне сәйкестендіріледі) және CSV / TXT нүктелері (атауы, X, Y, H, код бағандары таңдалады); координаттар жүйесі — WGS 84, UTM, СК-42 (Гаусс–Крюгер) не тахеометрдің жергілікті жүйесі (тірек нүктесі мен тордың бұрылуы бойынша). **Нүктелерден горизонтальдар:** биіктік белгілерінен Делоне үшбұрыштауы (TIN) арқылы, қимасы мен тегістеуі таңдалады, қайта құрғанда ескілері ауыстырылады; қорғанның бетіндегі тас үйінді мен ойық (тонау шұңқыры) контурдың ішінде көрсетіледі. Жоспарда аудандар мен сызықтар нысандардың астында, белгілер мен жазулар үстінде, сызба аймағымен қиылады, масштабқа әсер етпейді, жеке жоспарда да шығады; жазуларды алдын ала қарауда сүйреуге болады (алыстаса — сілтеме сызығы). Белгілер «Жоспар» панеліндегі тізімде; картада тұтқалармен түзетіледі. Сипаттамасы — [docs/PLAN-STAGE3.md](docs/PLAN-STAGE3.md). Тест: `npm run smoke:plan`, `node scripts/test-plan.mjs`.
- Өлшеу құралдары: сызғыш (сызықтарға магниттеледі, перпендикуляр), бұрышты туралау.
- Карта қабаттары — сыртқы сервистерден: OpenStreetMap, OpenTopoMap, Esri World Topo, **КСРО Генштабы топокарталары** (nakarte.me: AtloMaps мозаикасы және 1:1 000 000), Esri спутник; үстіңгі қабаттар (атаулар, жолдар). «Карта қабаттары → Сыртқы карта қосу» арқылы кез келген XYZ тайл-сервисін (QGIS «XYZ Tiles» пішімі) қосуға болады.
- Үстіңгі WMS қабаттары: **НИПД геопорталы** (map.gov.kz — мемлекеттік шекара, облыс пен аудан шекаралары, елді мекендер шекаралары, гидрография, автомобиль жолдары, темір жолдар) және «WMS қосу» арқылы кез келген WMS 1.1.1 / 1.3.0 сервисі: мөлдірлік, стиль, реті, нысан туралы ақпарат (оң жақ мәзір). Тек онлайн режимде. Толығырақ — [docs/WMS.md](docs/WMS.md).
- Экспорт: **GeoJSON**, **сызба (PNG)**, сызбасы бар **Word (DOCX)** құжаты; бірнеше аймақты бір DOCX-ке және QGIS стилі бар GeoJSON-ға біріктіру.
- Аймақтарды сақтау — компьютердің өзінде (интернетсіз де жұмыс істейді; карта тайлдары үшін интернет керек).
- **Плагиндер (міндетті емес).** **Баптаулар → Плагиндер** (не **Файл → Плагиндер…**): үшінші тарап әзірлеушілерінің `.muraplug` плагиндерін орнату (тексеру нәтижесі, сұратылған рұқсаттар, жауапкершілік ескертуі), қосу/өшіру, баптаулар, рұқсаттарды басқару, жою (жоба деректері өзгермейді), барлығын уақытша тоқтату. Плагин бағдарламаның кодына тимейді: ол бөлек оқшауланған процесте, желісіз (бөлек рұқсатсыз), жоба деректерін тек оқып жұмыс істейді, өз әрекетін тек «Қорғау аймағы → Нәтиже және экспорт», «⋯ Қосымша құралдар» мәзіріне және белгі терезесіндегі «Плагин ұсынысы» өрісіне қосады (ұсынысты таңдап, сақтауды пайдаланушы өзі басады). Ұсынылған (Mura GIS әзірлеушісі жасаған, бағдарламамен бірге келеді, бір батырмамен орнатылады) үлгі плагин — **NIPD GeoJSON Exporter**: қорғау аймақтарынан тек ескерткіш аумағының полигонын алып, НИПД атрибуттар кестесіне (name, category_level, type, monument_kind, inclusion_date, included_by_authority, responsible_organization, website_link) сәйкестендіреді, ағымдағы не барлық сақталған аймақтарды бір GeoJSON-ға жазады (QazTRF-23 белгісімен); қайталанатын өрістер бір рет енгізіледі. Екінші ұсынылған плагин — **Атау сәйкестендіргіш**: ескерткіштер тізімін бекіткен қаулының қазақша және орысша файлдарын (DOCX не мәтіні бар PDF, кемінде 2 файл; adilet.zan.kz-тен жүктелгені де) өзі талдайды — тіл, қаулының нөмірі мен күні, аудандар, атауы, мерзімі, түрі, орналасқан жері; белгі қойғанда не атауын жаза бастағанда белгі терезесінде (және қорғау аймағының мәліметтер терезесінде) ресми тізімнен ұқсас ескерткіштер ұсынылады (рим цифры, қ/к, ұ/у айырмасы ескеріледі; «ауылдан N км» сипаттамасы бойынша, ауыл «Өзге нысандарда» болса, шамамен орны да есептеледі), таңдалса өрістер екі тілде толтырылады. Файлдың өзі сақталмайды, тізімді кез келген уақытта өшіруге болады. Өз плагиніңізді жазу — [`plugin-sdk/`](plugin-sdk/README.md) (бастапқы кодсыз), архитектурасы — [`docs/PLUGINS.md`](docs/PLUGINS.md). Плагинсіз қауіпсіз іске қосу: `--no-plugins`.

## Деректер қайда сақталады

Барлық деректер — жобаның `.gpkg` файлында (орнын жоба құрғанда өзіңіз таңдайсыз; мәзір: **Файл → Жоба қалтасын ашу**). Басқа компьютерге көшіру үшін сол файлды көшірсеңіз жеткілікті.
`%APPDATA%\Mura GIS\data\` қалтасында тек соңғы жобалар тізімі (`recent.json`) және әр жобаның соңғы ашылған кездегі көшірмесі (`backups\`) сақталады.
Ескі нұсқалардың (1.2.x) деректері (`qorgau.json`, `marks.json`, `routes.json`) өшірілмейді: жаңа жоба құрғанда «Бұрынғы нұсқадағы деректерді жобаға көшіру» белгісін қойсаңыз, олар жобаға көшіріледі.
Қорғау аймақтарын JSON арқылы алмасу да қалды: **Файл → Сақталған аймақтарды файлға экспорттау / файлдан импорттау**.

## Әзірлеушілерге

Mura GIS — дербес бағдарлама, оның барлық коды осы репозиторийде. Бағдарлама ешбір сайтқа не серверге тәуелді емес: деректер компьютерде сақталады, карта қабаттары ашық сыртқы тайл-сервистерден жүктеледі (`src/js/basemaps.js`).

```bash
npm install
npm run vendor    # Leaflet-ті node_modules-тен src/vendor/ ішіне жаңарту (қажет болғанда)
npm start         # бағдарламаны іске қосу
npm run smoke     # түтін тесті: есептеу, DOCX, сақтау
npm run smoke:marks  # белгі қою: сұрыптау, режимдер, GeoJSON / DOCX / PDF
npm run smoke:routes # маршруттар: сызу, импорт, жол табу
npm run smoke:plugins # плагиндер: орнату, NIPD экспорты, атау сәйкестендіргіш, оқшаулау, қате/шексіз цикл
npm run plugins:pack  # plugin-sdk үлгілерінен .muraplug жинау
npm run dist:win  # Windows орнатқышы → dist/
```

Код құрылымы:
- `main/` — Electron негізгі процесі: терезе, мәзір, жобалар (`projects.js` — ашық жоба, соңғы жобалар; `gpkg-read.js` — бөтен GeoPackage-ті оқу және координаттарды түрлендіру; `gpkg.js` — GeoPackage файлы, SQLite — Electron-ның ішіндегі `node:sqlite`), қабаттарды сақтау (`store.js`, `marks.js`, `routes.js`), жаңартулар, PDF;
- `src/index.html` — басты бет; `src/css/` — стильдер (`base.css` — негізгі, `maptool.css` — карта интерфейсінің қабығы, `desktop.css` — жұмыс үстелі, `marks.css` — белгілер);
- `src/qorgau/` — «Қорғау аймағы» қызметі (есеп, сызба, DOCX/GeoJSON экспорты, интерфейс);
- `src/marks/` — «Ескерткіштер» қызметі; `src/routes/` — «Маршруттар» (`graph.js` — желі және жол іздеу, `tracks.js` — GPX/KML/GeoJSON); `src/js/` — қызметтер жолағы (`services.js`), бастапқы терезе мен баптаулар (`project.js`), GeoPackage импорты (`gpkg-import.js`), карта қабаттары, оң жақ мәзір, жұмыс үстелі қабығы т.б.;
- `main/plugins/`, `src/js/plugins-ui.js` — плагиндер жүйесі; `plugin-sdk/` — Plugin SDK (API, типтер, үлгілер, құралдар);
- `src/vendor/` — Leaflet, fflate, Lucide иконкаларының лицензиясы (офлайн жұмыс үшін жергілікті көшірмелер).

Архитектуралық қағидалар — [`CLAUDE.md`](CLAUDE.md), даму жоспары — [`docs/ROADMAP.md`](docs/ROADMAP.md).

### Жаңа нұсқа шығару

1. `npm test` және `npm run smoke` (қажет болса `smoke:marks`, `smoke:routes`).
2. `package.json` → `version` өсіріңіз (мыс. `1.3.1`), `build/release-notes.md` ішіне осы нұсқаның өзгерістерін жазыңыз (релиз бетінің мәтіні), commit жасап, `main`-ге жіберіңіз.
3. Тег жіберіңіз: `git tag v1.2.1 && git push origin v1.2.1`

GitHub Actions (`.github/workflows/release.yml`) Windows-та құрастырады: тег пен `package.json` нұсқасы сәйкес екенін тексереді, маршрут желісінің тестін өткізеді, орнатқыш пен портативті нұсқаны [Releases](https://github.com/BERIKKKK/mura-gis/releases) бетіне жариялайды; орнатылған бағдарламалар жаңа нұсқаны өздері жүктейді. Тегті қайта жариялау керек болса — Actions → Release → **Run workflow** (тегті көрсетіп). Өз компьютерден шығару да бұрынғыдай жұмыс істейді: `npm run release:win` (`GH_TOKEN` керек).
