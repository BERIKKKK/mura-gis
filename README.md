# Mura GIS

Тарих және мәдениет ескерткіштерінің **қорғау аймағын**, **құрылыс салуды реттеу аймағын** және **қорғалатын табиғи ландшафт аймағын** есептейтін жұмыс үстелі бағдарламасы.

Есептеу ҚР Мәдениет және спорт министрінің 2020 жылғы 14 сәуірдегі № 86 бұйрығымен бекітілген қағидалардың 7–9-тармақтарына сәйкес жүргізіледі.

| `MuraGIS-Setup-X.Y.Z.exe` | Windows орнатқышы. Жаңа нұсқалар **автоматты түрде** жүктеліп, орнатылады. |
| `MuraGIS-Portable-X.Y.Z.exe` | Орнатусыз іске қосылатын нұсқа (флешкадан да жұмыс істейді). Жаңартуды «Анықтама → Жаңартуларды тексеру» арқылы қолмен жүктейсіз. |

> Бағдарлама цифрлық қолтаңбасыз таратылады, сондықтан алғаш іске қосқанда Windows SmartScreen «Белгісіз баспагер» деп ескертуі мүмкін: **Толығырақ → Бәрібір іске қосу**.

Linux нұсқасы (AppImage, .deb) кейін шығады.

## Мүмкіндіктері

- Ескерткіш шекарасын картада нүктелермен белгілеу, координаттарды кез келген пішімде енгізу (ондық градус, ° ′ ″, Excel-ден тізіммен), азимут пен қашықтық бойынша қосу, дәл өлшемді тіктөртбұрыш.
- Үш аймақ шекарасын автоматты есептеу, аудандарын шығару. Шекара дайын болғанда **Аяқтау** басылады: мәліметтер терезесі ашылып, қорғау аймағы сол жерден сақталады (белгі қоюмен бірдей логика; жолақта бөлек «Сақтау» жоқ). Терезеде белгіленген ескерткішті таңдасаңыз, мәліметтер белгіден толтырылады; шекара ішінде белгі болса, ол өзі таңдалады. Белгілер панеліндегі «Қорғау аймағы» — сол белгіден жаңа аймақ бастайды. Сақталған жазбалар — «Қорғау аймақтары» панелінде.
- Құралдар жолағы жұмыс реті бойынша: белгілер → қорғау аймағының шекарасы мен деректері → өлшеу → көрініс (сыйғызу, толық экран). Сақталған аймақты өңдеу — «Қорғау аймақтары» тізіміндегі «Өңдеу».
- Тінтуірдің оң жақ батырмасы: картада — координатаны көшіру (ондық градус, ° ′ ″), алмасу буферіндегі координатаны қою (картадан көрсету), осы жерге белгі не шекара нүктесін қою; белгіде — координатасын көшіру, өңдеу, қорғау аймағы; мәтін өрістерінде — қию, көшіру, қою.
- **Бүкіл Қазақстан**: 17 облыс және 3 республикалық маңызы бар қала, олардың аудандары мен облыстық маңызы бар қалалары (ағымдағы атаулар). Соңғы таңдалған облыс есте сақталады — қорғау аймағына да, белгіге де әдепкі болады, қажет болса ауыстырылады.
- **Белгі қою** — ескерткіштерді картада нүктемен белгілеу (қорғау аймағынан бөлек функция): атауы, мерзімі, облыс/аудан, орналасқан жері, түрі (Заңның 5-бабы), санаты (6-бап), мәртебесі. Белгінің иконкасы — түріне қарай (QGIS-пен ортақ SVG шартты белгілер, `src/marks/symbols/`), түсі — санатына қарай: халықаралық — күлгін, республикалық — қызыл, жергілікті маңызы бар — қызғылт сары, анықталмаған — сұр. Белгілер **GeoJSON** (нүктелер) және ескерткіштер тізімі ретінде **Word (DOCX)** мен **PDF** кестесіне экспортталады — облыс әкімдігі қаулысына қосымшадағы «Мемлекеттік тізім» үлгісімен, қаулы мәтінінсіз, әр санат бөлек кестеде; санат, облыс, аудан және атау бойынша сұрыпталады, атаудағы рим цифрлары (латын да, кирилл де: IV / ІҮ → 4, V / Ү → 5) санмен салыстырылады.
- Өлшеу құралдары: сызғыш (сызықтарға магниттеледі, перпендикуляр), бұрышты туралау.
- Карта қабаттары — сыртқы сервистерден: OpenStreetMap, OpenTopoMap, Esri World Topo, **КСРО Генштабы топокарталары** (nakarte.me: AtloMaps мозаикасы және 1:1 000 000), Esri спутник; үстіңгі қабаттар (атаулар, жолдар). «Карта қабаттары → Сыртқы карта қосу» арқылы кез келген XYZ тайл-сервисін (QGIS «XYZ Tiles» пішімі) қосуға болады.
- Экспорт: **GeoJSON**, **сызба (PNG)**, сызбасы бар **Word (DOCX)** құжаты; бірнеше аймақты бір DOCX-ке және QGIS стилі бар GeoJSON-ға біріктіру.
- Аймақтарды сақтау — компьютердің өзінде (интернетсіз де жұмыс істейді; карта тайлдары үшін интернет керек).

## Деректер қайда сақталады

`%APPDATA%\Mura GIS\data\qorgau.json` (қорғау аймақтары) және `marks.json` (ескерткіш белгілері) (мәзір: **Файл → Деректер қалтасын ашу**). Әр сақтаудан кейін алдыңғы күйі `qorgau.json.bak` болып қалады.
Басқа компьютерге көшіру: **Файл → Сақталған аймақтарды файлға экспорттау / файлдан импорттау**.

## Әзірлеушілерге

Құралдың бастапқы коды [aktobenasledie.kz](https://aktobenasledie.kz) сайтының әкімші панеліндегі «Қорғау аймағы» құралымен ортақ: `src/qorgau/`, `src/css/admin.css`, `src/css/maptool.css` және `src/index.html` сайттан **автоматты көшіріледі** — оларды осы жерде қолмен өзгертпеңіз. Карта қабаттары (`src/js/basemaps.js`) сайттан көшірілмейді — бағдарламаның өз модулі, сайттың топокартасына жүгінбейді.

```bash
npm install
npm run sync      # сайт қалтасынан құралды көшіру (site.config.json → siteDir)
npm start         # бағдарламаны іске қосу
npm run smoke     # түтін тесті: есептеу, DOCX, сақтау
npm run smoke:marks  # белгі қою: сұрыптау, режимдер, GeoJSON / DOCX / PDF
npm run dist:win  # Windows орнатқышы → dist/
```

Бағдарламаға ғана тән код: `main/` (Electron негізгі процесі, сақтау, жаңартулар, PDF), `src/css/desktop.css`, `src/js/desktop.js`, `src/js/basemaps.js`; «Белгі қою» функциясы — `src/marks/`, `src/css/marks.css` (сайттан көшірілмейді, `npm run sync` оларды index.html-ге өзі қосады).

### Жаңа нұсқа шығару

1. `npm run sync` (сайттағы құрал өзгерген болса), `npm run smoke`.
2. `package.json` → `version` өсіріңіз (мыс. `1.0.1`), commit жасаңыз.
3. `git tag v1.0.1 && git push origin main v1.0.1`

GitHub Actions Windows файлдарын құрастырып, [Releases](https://github.com/BERIKKKK/mura-gis/releases) бетіне жариялайды; орнатылған бағдарламалар жаңа нұсқаны өздері жүктейді.
