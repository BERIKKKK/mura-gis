## Mura GIS 2.4.2

### Жаңа ұсынылған плагин: Атау сәйкестендіргіш
- **«Баптаулар → Плагиндер → Плагин орнату → Ұсынылған плагиндер»** бөлімінен бір батырмамен орнатылады (интернет керек емес).
- **«⋯ → Қаулылар (атау сәйкестендіру)…»**: ескерткіштер тізімін бекіткен қаулының қазақша және орысша файлдарын таңдайсыз —
  DOCX не мәтіні бар PDF, кемінде 2 файл (adilet.zan.kz-тен жүктелгені де жарайды). Плагин құжатты өзі талдайды: тілі, қаулының
  нөмірі мен күні, тіркеу нөмірі, редакциясы, аудандар, әр ескерткіштің атауы, мерзімі, түрі, орналасқан жері.
- Тексеру терезесінде құжаттағы ескерткіш санын енгізуге болады — оқылған сан сәйкес келмесе, ескертіледі.
- **Белгі қойғанда** не атауын жаза бастағанда белгі терезесінде **«Плагин ұсынысы»** шығады: ресми тізімнен ұқсас ескерткіштер
  (рим цифры, қ/к, ұ/у айырмасы ескеріледі, нөмірі бөлек тексеріледі; ауданы сәйкес келгені жоғары тұрады; «ауылдан N км»
  сипаттамасы бойынша, ауыл «Өзге нысандарда» болса, шамамен қашықтық та көрсетіледі). Таңдасаңыз, атауы, мерзімі,
  орналасқан жері екі тілде, түрі, санаты, ауданы толтырылады; сақтауды өзіңіз басасыз.
- Файлдың өзі сақталмайды — тек тізім. Жүктелген қаулыны кез келген уақытта өшіруге болады.

### Плагиндер (әзірлеушілерге)
- Plugin API 1 ішінде, тек қосымша: `files.import` рұқсаты және `mura.files.open()` (файлды пайдаланушы таңдайды, плагин жолын
  білмейді); `mark.suggest` кеңейту нүктесі (белгі терезесіндегі ұсыныстар). SDK: типтер, схема, құжаттама, тестілеу құралы
  (`fixture.files`, `fixture.storage`, панель әрекеттері, плагиннің өз `lib/*.js` файлдары).

### Деректер
- Жоба файлдары (.gpkg) өзгермейді. Жаңарту бар нұсқаның үстінен орнатылады.
