## Mura GIS 2.4.4

### Атау сәйкестендіргіш: қорғау аймағында да, түсінікті кеңес
- **Қорғау аймағы**: шекараны белгілеп, «Аяқтау» басқанда ашылатын мәліметтер терезесінде де **«Плагин ұсынысы»** шығады —
  атауын жаза бастасаңыз, ресми тізімнен ұқсас ескерткіштер ұсынылады; таңдасаңыз, атауы, мерзімі, орналасқан жері (екі тілде),
  ауданы, ескерткіш түрі толтырылады (аймақ өлшемдері түріне сай). Тек ұсыныста бар өрістер жазылады.
- **Кеңес**: атауы әлі жазылмаған не тізімде табылмаған кезде өріс жасырылмайды — «Атауын жаза бастаңыз — ресми тізімнен
  ұсынылады (№ 306 қаулы — 863)» не «"…" ресми тізімде табылмады» деген кеңес шығады.
- Плагин 1.1.0 нұсқасына жаңартылды: **Баптаулар → Плагиндер → Плагин орнату → Ұсынылған плагиндер → Атау сәйкестендіргіш →
  Жаңарту**. Жүктелген қаулылар сақталады.

### Әзірлеушілерге
- Plugin API 1 (тек қосымша): `zone.suggest` кеңейту нүктесі; `mark.suggest` / `zone.suggest` нәтижесінде `hint` (кеңес).

### Деректер
- Жоба файлдары (.gpkg) өзгермейді. Жаңарту бар нұсқаның үстінен орнатылады.
