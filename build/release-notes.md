## Mura GIS 2.5.4

### Түзету
- Бағдарламаны ашқанда кейде шығатын «A JavaScript error occurred in the main process — Object has been destroyed»
  қатесі түзетілді. Ол алдыңғы терезе жабылып, бірақ бағдарлама әлі толық тоқтамаған кезде (мысалы, жаңарту
  орнатылып жатқанда) қайта ашқанда шығатын. Енді мұндай жағдайда бағдарлама ескі процесс жабылған соң өздігінен ашылады.

Бұрынғы жобалар өзгеріссіз ашылады. Жаңарту бар нұсқаның үстінен орнатылады.
