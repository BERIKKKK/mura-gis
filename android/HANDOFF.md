# Келесі сессияға: ағымдағы күй (2026-11-20)

Тармақ: `ccr-949cba91-psw3xy` (негізі — жұмыс үстелі релизі v1.3.1). Барлық жұмыс `android/` және
`.github/workflows/android.yml` ішінде; жұмыс үстелінің коды өзгертілмеген.

## Жасалды
- Кезең 1: репозиторий талданды, архитектура — `docs/ARCHITECTURE.md`.
- Кезең 2–4: `:core` (толық, тестіленген) және `:app` (Compose + MapLibre + SQLite + WorkManager) — барлық экрандар жазылды:
  ескерткіштер, маршруттар, карталар (жүктеу, импорт, лицензия саясаты, офлайн ауысу), баптаулар, екі тіл.
- Кезең 6 (ішінара): CI/CD (`android.yml`), CHANGELOG, README, нұсқа `1.0.0-alpha.1` (альфа — pre-release).
- `app/src/androidTest` — құрылғы тестілері жазылды (CI-ға қосылмаған).

## Маңызды шектеу
Бұл контейнерде Android SDK жоқ (dl.google.com / maven.google.com желі саясатымен жабық; ортаны өзгерту ұсынысы қабылданбады),
сондықтан `:app` тек GitHub Actions-та компиляцияланады. `:core` жергілікті: `./gradlew -PcoreOnly=true :core:test`.

## Келесі қадамдар (рет бойынша)
1. Actions → Android → соңғы іске қосу: `Debug APK` және `Lint` қадамдары. Алғашқы іске қосу (run 44709629070) аяқталмай қалды —
   қате болса, `mcp__github__get_job_logs` (failed_only) арқылы оқып, `:app` компиляция қателерін түзету.
   Соңғы коммитте тағы: ImportMapWorker түзетуі, androidTest, ui-test тәуелділіктері — олар да CI-да тексерілуі керек.
2. `android.yml`-ге эмулятор жұмысын қосу (мыс. `reactivecircus/android-emulator-runner@v2`, api-level 30, `:app:connectedDebugAndroidTest`).
3. APK-ны нақты құрылғыда `docs/TESTING.md` 1–12 сценарийлері бойынша тексеру, нәтижелерді сол файлға жазу.
4. Қолтаңба құпияларын қосу (README.md), содан кейін ғана `git tag android/v1.0.0-alpha.1` — релиз «Pre-release» болып жарияланады.
5. Кезең 5 (жетілдіру): тізімдегі белгілерді экран өлшеміне қарай баптау, жүктеу аумағын картадан саусақпен таңдау т.б.
