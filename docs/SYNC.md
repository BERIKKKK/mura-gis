# Синхрондау (Desktop ↔ Android, Google Drive)

Аккаунт міндетті емес. Қосылмаса, екі нұсқа да бұрынғыдай толық жергілікті жұмыс істейді. Қосылса, ескерткіш нүктелері
мен маршруттар пайдаланушының **өз Google Drive-ындағы** Mura GIS-тің жасырын аумағына (`appDataFolder`, рұқсаты —
`drive.appdata`) жазылады. Mura GIS сервері жоқ: деректер, координаталар және токендер тек құрылғы мен Google арасында жүреді.

## Құрылым

| Бөлік | Desktop (Electron) | Android |
|---|---|---|
| Ортақ ережелер (қызметке тәуелсіз) | `main/sync/engine.js` | `core/.../core/sync/SyncEngine.kt` |
| Жазба пішімі ↔ жергілікті дерек | `main/sync/index.js` → `gpkgLocal` (.gpkg `marks`, `routes`) | `core/.../sync/SyncRecords.kt`, `StoreSyncLocal` (`LocalStore`) |
| Сақтау қызметі: Google Drive | `main/sync/gdrive.js` | `app/.../sync/GoogleDrive.kt` |
| Кіру (OAuth) | `main/sync/google-auth.js` — браузер, 127.0.0.1, PKCE; жаңарту токені `safeStorage` (DPAPI) | `app/.../sync/GoogleAuth.kt` — Play Services `AuthorizationClient` |
| Кезек, кесте, күй | `main/sync/index.js` (`SyncManager`) | `app/.../sync/SyncManager.kt` |
| Интерфейс | `src/js/sync-ui.js` — «Баптаулар → Синхрондау», күй жолағы | `ui/SyncUi.kt` — «Баптаулар → Синхрондау» |

Жаңа қызмет (OneDrive, Dropbox) — тек бір модуль: `list() / read(file) / write(name, text)` + кіру, қате кодтары
бірдей (`offline`, `auth`, `quota`, `rate`, `server`). Қозғалтқыш, жазба пішімі мен id-лер өзгермейді.
Күй мен кезек `қызмет-аккаунт` кілтімен бөлек сақталады — аккаунт не қызмет ауысса, жергілікті жобалар жаңа қоймаға
тек пайдаланушы «Осы жобаны синхрондау» / «Осы аккаунтқа жүктеу» басқанда жүктеледі.

## Бұлттағы файлдар (`mura-sync/1`)

- `mura.<жоба id>.<құрылғы id>.json` — бір құрылғының бір жобадағы күйі: `project` (атауы, облысы, ауданы, `updated_at`),
  `device`, `records: [{ t: "mark"|"route", id, vv, d | del }]`. **Әр файлды тек өз құрылғысы жазады** — Drive-та қатар
  жазу қайшылығы болмайды.
- `mura.index.<құрылғы id>.json` — құрылғы синхрондайтын жобалар тізімі («Бұлттағы жобалар» үшін).

Жоба id-і — 16 hex: Desktop-та `.gpkg` ішіндегі `mura_project.sync_id`, Android-та `sync_projects.id` және жазбалардағы
`project_id` (схема v3, тек қосымша баған/кесте). Жазба id-і — бұрынғыдай ескерткіштің/маршруттың 16 hex `id`-і.

Жазба `d` — Desktop .gpkg жазбасының пішімі (`name`, `name_ru`, `period`, … `lat`, `lon`; маршрут — `pts [[lat, lon]]`) +
міндетті емес қосымшалар: `oblast_ru`, `district_ru`, маршрутта `*_ru` және `pt_marks [[нүкте №, ескерткіш id]]`.
Desktop белгісіз өрістерді өңдегенде енді жоғалтпайды (`MarksStore.extras`, `RoutesStore.extras`).

## Ережелер (екі платформада бірдей)

1. Әр өзгеріс алдымен құрылғыға жазылады; жергілікті өзгеріс — соңғы синхрондалған мазмұнмен (хеш) салыстыру арқылы
   табылады (уақыт белгісі ғана өзгерсе — өзгеріс емес). Желі жоқ кезде кезекте тұрады, «күтілетін өзгерістер» саны көрінеді.
2. Әр нұсқада нұсқа векторы `vv = { құрылғы: санауыш }`. Бір нұсқа екіншісін қамтыса — жаңасы қабылданады.
3. Өшіру — «tombstone» нұсқа: офлайн тұрған құрылғы өшірілген жазбаны қайта тірілтпейді.
4. Қатар өзгерген (vv салыстырылмайды) және мазмұны өзге — **қайшылық**: екі нұсқа да сақталады, құрылғыда өз нұсқасы
   қалады, пайдаланушы таңдайды. «Өшірілді ↔ өңделді» — да қайшылық. Таңдалған нұсқа екеуін де қамтиды → барлық құрылғы қабылдайды.
5. Алғаш қосылғанда (күй жоқ) жазбалар id бойынша біріктіріледі: мазмұны бірдей — бір жазба, өзге — қайшылық. Көшірме жасалмайды.
6. Басқа жазбаларға әсер жоқ — біріктіру жазба деңгейінде.
7. Android-та сақтық көшірмеден қалпына келтірілсе, күй тасталады (5-ереже) — көшірмеде жоқ жазбалар басқа құрылғыларда өшірілмейді.

Тесттер: `node scripts/test-sync.mjs` (қозғалтқыш, нақты .gpkg, Drive модулі — fetch ауыстырылған),
`npm run smoke:sync` (интерфейс), Android: `SyncEngineTest` — сол сценарийлер + Android дерекқоры + **жұмыс үстелінің өз
қозғалтқышымен бір «бұлт» арқылы алмасу** (`android/tools/desktop-compat.mjs sync`).

## Google Cloud баптауы (бір рет, әзірлеуші)

Екі нұсқа бір `appDataFolder`-ді көруі үшін OAuth клиенттері **бір Google Cloud жобасында** болуы керек.

1. console.cloud.google.com → жаңа жоба (мыс. «Mura GIS») → **APIs & Services → Library → Google Drive API → Enable**.
2. **OAuth consent screen** (Google Auth Platform): түрі *External*, қолданба атауы, байланыс e-mail; **Data access**-ке
   `.../auth/drive.appdata` қосу. Тестілеу кезінде *Testing* режимі және *Test users* тізіміне өз аккаунттарыңыз;
   барлығына ашу үшін *Publish app* (drive.appdata шектелген (restricted) рұқсат емес).
3. **Clients → Create client → Desktop app** → `Client ID` мен `Client secret`-ті `main/sync/google-oauth.json`-ға жазу
   (не `MURA_GOOGLE_CLIENT_ID` / `MURA_GOOGLE_CLIENT_SECRET` айнымалылары). Орнатылған қолданбада бұл «secret» Google
   ережесі бойынша құпия саналмайды, бірақ репозиторий ашық болғандықтан оны коммиттеу — сіздің шешіміңіз.
4. **Clients → Create client → Android**: пакет `io.github.berikkkk.muragis.mobile`, SHA-1 — шығарылым кілтінің
   (`keytool -list -v -keystore %USERPROFILE%\.mura-gis-keys\mura-gis-release.jks -alias muragis`).
   Debug жинағы үшін тағы бір Android клиенті: пакет `io.github.berikkkk.muragis.mobile.debug`, SHA-1 —
   `%USERPROFILE%\.android\debug.keystore` (alias `androiddebugkey`, құпиясөз `android`). Android кодына client ID қажет емес.

## Қолмен тексеру (нақты аккаунтпен)

1. Desktop: «Баптаулар → Синхрондау → Google арқылы кіру» → келісім мәтіні → браузер → «Аккаунт қосылды».
2. Desktop: «Осы жобаны синхрондау» → «Синхрондалды», күтілетін өзгеріс 0.
3. Android: «Баптаулар → Синхрондау → Google арқылы кіру» (сол аккаунт) → жоба тізімде пайда болады → белсенді ету.
4. Телефонда нүкте қою → компьютерде (бағдарлама ашық, ≤ 5 мин не «Қазір синхрондау») сол жобада көрінеді.
5. Компьютерде маршрутты өзгерту → телефонда жаңарады.
6. Телефонды ұшақ режиміне қойып нүкте қосу/өшіру → «Интернет жоқ», күтілетін өзгерістер > 0 → желіні қосу → өздігінен жіберіледі.
7. Бір нүктені екі құрылғыда офлайн өзгерту → екеуінде де қайшылық → бірінде таңдау → екіншісінде жабылады.
8. Компьютерде өшіру, телефон офлайн → телефон қосылғанда жазба жоғалады, қайта пайда болмайды.
9. «Аккаунтты ажырату» → деректер орнында, синхрондау тоқтады. myaccount.google.com → Security → рұқсатты қайтару →
   «Google рұқсаты қайтарылған» хабары.

## Шектеулер

- Синхрондау қолданба ашық тұрғанда ғана жүреді (фондық қызмет жоқ — талап бойынша).
- Синхрондалмайды: өзге нысандар (`places`), қорғау аймақтары, «Жоспар», импортталған нүктелер, офлайн карталар, фото, құжаттар.
- Desktop-та авто сақтау өшік және жобада сақталмаған өзгеріс болса, ол жоба сақталғанға дейін синхрондалмайды.
- Жоба мәліметтері (атауы, облысы, ауданы) — соңғы өзгергені қалады (қайшылық көрсетілмейді).
- Бір id екі түрлі жобада болса, Android оны екінші жобаға қабылдамайды (бірі жоғалмас үшін) — күйде `skipped` болып белгіленеді.
