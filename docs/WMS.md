# Үстіңгі WMS қабаттары: НИПД геопорталы және қолданушы сервистері

Код: `src/js/wms.js` (ядро), `src/js/wms-ui.js` (мәзір бөлімі, «WMS қосу» терезесі, GetFeatureInfo), `main/wms.js`
(мәтіндік сұраулар), мәзір құрылымы — `src/js/basemaps.js`. Тест: `npm run smoke:wms` (`MURA_WMS_LIVE=0` — тек желісіз бөлік).

## Не істейді

- WMS 1.1.1 және 1.3.0: GetCapabilities (қабаттар, стильдер, CRS, шекаралар, атрибуция — ата-ана қабаттан мұраланады),
  GetMap (512 px тайлдар), GetFeatureInfo (оң жақ мәзір → «Үстіңгі қабаттардан ақпарат»).
- EPSG:3857 және EPSG:4326; 1.3.0 + EPSG:4326 кезінде BBOX осьтері `lat,lon` ретімен жіберіледі, 1.1.1-де — `lon,lat`.
- Мөлдір PNG (`TRANSPARENT=TRUE`); `EXCEPTIONS=XML` (1.3.0) / `application/vnd.ogc.se_xml` (1.1.1) — сервер қатесі суретке
  салынбайды, XML жауап тайл ретінде көрсетілмейді.
- Сұраулар: карта тоқтағанда ғана (`updateWhenIdle`), масштабтау кезінде жоқ, ескірген тайлдарды Leaflet тоқтатады,
  сұрау тек қабат шекарасының (bbox) ішінде жіберіледі. Офлайн кэш, жаппай жүктеу жоқ.
- HTTPS сертификатын тексеру өшірілмейді (`net.fetch` — Chromium-ның әдеттегі тексерісі).
- Интернет болмаса: «Офлайн режимде қолжетімсіз» жазуы; бағдарламаның қалған бөлігі жұмыс істей береді;
  байланыс қалпына келгенде қабаттар қайта сұралады.

## Қабаттар реті (төменнен жоғары)

| Деңгей | Не | zIndex (tilePane ішінде) |
|---|---|---|
| 1 | Негізгі карта | 1 |
| — | Esri / өз XYZ үстіңгі қабаттары (бұрыннан бар) | 5 |
| 2 | НИПД әкімшілік шекаралары | 10+ |
| 3 | НИПД гидрография және көлік | 30+ |
| 4 | НИПД атаулары (серверде табылмады — бос) | 50+ |
| — | Қолданушының WMS қабаттары | 70+ |
| 5–8 | Қорғау аймақтары, маршруттар, белгілер, сызу/өлшеу | overlayPane / markerPane — тайлдардан жоғары |

Топ ішінде қабаттардың ретін ▲▼ батырмаларымен өзгертуге болады. Тайл суреттері тінтуір оқиғаларын ұстамайды —
нүкте қою, маршрут, қорғау аймағын сызу құралдарына кедергі жоқ.

## Сақталатын баптаулар (localStorage, XYZ карталарынан бөлек)

| Кілт | Мазмұны |
|---|---|
| `mura.wms-services` | қолданушының сервистері: `id, label, url, version, ver, getMap, getInfo, infoFormats, format, crs, style, attribution, opacity, layers[], created_at, updated_at` |
| `mura.wms-state` | `items[id] = { on, opacity, style }`, `order = { admin, hydro, names, user }` |
| `mura.wms-nipd-meta` | НИПД қабаттарын тексеру нәтижесі (7 күн) және «Қайта тексеру» кезінде алынған сипаттамалар — карта деректері емес |

## НИПД геопорталы: тексеру есебі (2026-11-25)

Сервер: `https://map.gov.kz/geoserver/wms` (GeoServer, «GeoNode Local GeoServer»; ұйым — «Геопортал Национальной
инфраструктуры пространственных данных Республики Казахстан»; `AccessConstraints: NONE`, `Fees: NONE`).
GetCapabilities 1.3.0: 12,7 МБ, **3124 қабат** (geonode 3024, gov 61, openmap 32, arm 7); жауап беру уақыты ≈ 47 с.
Қабаттардың ешқайсысында `<Attribution>` жоқ — сондықтан бастапқы атрибуция қолданылады:
«Дереккөз: ҚР Ұлттық кеңістіктік деректер инфрақұрылымының мемлекеттік геопорталы (map.gov.kz)».

Бағдарламаға қосылған қабаттар (әрқайсысы GetMap сұрауымен Ақтөбе облысының аумағында тексерілді; бәрі авторизациясыз,
`queryable="1"`, бір ғана стиль):

| Бағдарламадағы атауы | Идентификатор(лар) | Сервердегі атауы | Стиль / шектеу |
|---|---|---|---|
| Мемлекеттік шекара | `geonode:border_rk` | Граница Республики Казахстан | қызыл контур, мөлдір фон |
| Облыстардың шекаралары | `geonode:border_regions` | Границы областей | қоңыр контур, мөлдір фон |
| Аудандардың шекаралары | `geonode:border_districts` | Границы районов | пунктир контур, мөлдір фон |
| Елді мекендердің шекаралары (9 облыс) | `geonode:almobl_kato_wgs84`, `aqmola_kato_wgs84`, `batys_kato_wgs84`, `kostanay_kato_wgs84`, `mangistau_kato_wgs84`, `orda_kato_wgs84`, `qarobl_kato_wgs84`, `turkistan_kato_wgs84`, `zhambyl_kato_wgs84` | Границы (районов и) населённых пунктов … области | **тек тұтас сұр бояу** (контур стилі жоқ) → әдепкі мөлдірлік 65%, интерфейсте ескерту; **Ақтөбе облысы жоқ** |
| Өзендер мен көлдер (гидрография) | `geonode:hydro_polygon_ca4c123b1e54d8e2baaf59cbfd688c22` | Гидрография | көк, мөлдір фон |
| Автомобиль жолдары | `geonode:roads_kz_sparse_ids_20261124` | Автомобильные дороги РК | категория бойынша түсті; атауында күн бар — серверде ауыстырылуы мүмкін, сонда «серверде жоқ» деп көрсетіледі |
| Темір жолдар | `geonode:railways_line` | Железные дороги (топо 25 000) | сызық, мөлдір фон |

GetFeatureInfo (`application/json`) жұмыс істейді: мысалы, Ақтөбе қаласында — `name_ru: Актюбинская область`
(`kato 150000000`) және `name_ru: Актобе Г.А.` (`kato 151000000`). `name_kz` өрісі серверде бос.

**Серверден табылмағандар** (бағдарламаға қосылмады, НИПД бөлімінде ақпарат ретінде көрсетіледі):

- ауылдық округтердің шекаралары — ұлттық не облыстық қабат жоқ;
- қалалар мен ауылдардың атаулары — жазуы бар қабат жоқ (`geonode:aktyubinskaya_oblast_area_point_name` тек нүкте
  ретінде салынады, атауы жоқ);
- географиялық және жер-су атаулары — жоқ;
- қазақша/орысша стиль нұсқалары — жоқ (әр қабатта бір стиль), сондықтан тіл таңдау қосылмады.

**Басқа шектеулер:**

- Жеке қабат каталогы (`/geoserver/geonode/<қабат>/wms`) кей қабаттар үшін 404 береді (гидрография, жолдар), сондықтан
  қолжетімділік GetCapabilities арқылы емес, 16×16 GetMap сұрауымен тексеріледі (`LayerNotDefined` → «серверде жоқ»).
- Сервер кейде қосылымды үзеді (ECONNRESET) не баяу жауап береді — тайл қатесі қайталанса, себебі анықталып күй
  ретінде көрсетіледі; басқа функцияларға әсері жоқ.
- Толық каталог (≈13 МБ) тек «Қайта тексеру» не «Барлық НИПД қабаттары…» басылғанда жүктеледі.
- Деректерді офлайн сақтау, жаппай жүктеу, қайта тарату — ресми рұқсат алынбайынша жасалмайды.
