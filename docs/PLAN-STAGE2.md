# «Жоспар», 2-кезең: қорым экспликациясы — жоба

> **Мәртебесі: іске асырылды.** Код: `main/plans.js` (анықтамалықтар, `cleanExpl`), `main/plan-geom.js` (тіктөртбұрыш),
> `src/plan/sheet.js` (белгілер, штрих, шартты белгілер, экспликация, жалғасы беттері), `src/plan/plan.js` (нысан терезесі,
> тіктөртбұрышты сызу, баптаулар). Тесттер: `scripts/test-plan.mjs`, `npm run smoke:plan`. Шешімдердің тізімі — 8-бөлім.

Негіз: техникалық тапсырманың 10-бөлімі және 2-кезеңнің қабылдау сынақтары. Бұл кезең 1-кезеңнің нысандарды сақтау, контур
салу және PDF шығару мүмкіндіктерін пайдаланады: жаңа модуль емес, бар `plan_objects` қабатына өрістер мен анықтамалықтар қосылады.

## 2. Анықтамалықтар

Кодтар — латынша, тұрақты (GeoPackage-те, GeoJSON-да сақталады, Android-пен ортақ бола алады); атаулар — интерфейс пен құжат тілінде.
Жаңа мән тек соңына қосылады, бар код өзгертілмейді (`places` түрлеріндегідей).

### 2.1. Нысан түрі (`kind`)

| Код | ҚАЗ | РУС | ТЗ-да | Белгі (контур жоқ кезде) |
|---|---|---|---|---|
| `kurgan` | Қорған | Курган | 1-кезең | толтырылған дөңгелек (бар) |
| `kesene` | Кесене | Мавзолей | ✓ | шаршы + ішінде шеңбер (күмбез) |
| `sagana` | Сағана там | Саганатам | ✓ | қос сызықты тіктөртбұрыш |
| `korshau` | Қоршау | Ограда | ✓ | үзік сызықты тіктөртбұрыш |
| `koitas` | Қойтас | Койтас | ✓ | ұштары домаланған көлденең блок |
| `kulpytas` | Құлпытас | Кулпытас | ✓ | тік стела, үсті домаланған, толтырылған |
| `sandyktas` | Сандықтас | Сандыктас | қосылды | тіктөртбұрыш + ортасында сызық |
| `ushtas` | Үштас | Уштас | қосылды | қатар тұрған үш шағын тік тас |
| `bestas` | Бестас | Бестас | қосылды | қатар тұрған бес шағын тік тас |
| `other` | Басқа нысан | Иной объект | 1-кезең | бос дөңгелек |

Сандықтас, үштас, бестас ТЗ-ның бастапқы тізімінде жоқ, бірақ Батыс Қазақстан қорымдарында құлпытас пен қойтаспен бірге жиі
кездеседі (Ажигали; Беки, Масат ата қорымдарының сипаттамалары) — пайдаланушының шешімімен анықтамалыққа қосылды.
Тізім реті: ТЗ-дағы бес түр, содан кейін қосылғандары, соңында «Басқа нысан».

### 2.2. Материал (`material`)

| Код | ҚАЗ | РУС | Штрих (ақ-қара басуға жарамды) |
|---|---|---|---|
| `brick_fired` | Күйдірілген кірпіш | Жжёный кирпич | 45° жиі тұтас сызықтар, аралығы 1,2 мм |
| `brick_raw` | Шикі кірпіш | Сырцовый кирпич | 45° сирек үзік сызықтар, аралығы 2,4 мм |
| `stone` | Табиғи тас | Природный камень | 45°/135° тор, аралығы 1,6 мм |
| `''` (бос) | — | — | штрихсыз (ақ) |

- ТЗ-дағы «табиғи кірпіш» атауы пайдаланушының шешімімен **«Табиғи тас»** деп бекітілді: кесілген не өңделген табиғи тас —
  ұлутас (известняк-ракушечник), известняк-песчаник плиталары т.б. ГОСТ 2.306-68-дегі «камень естественный» белгісіне сай.
  Тас түрін (ұлутас, известняк, гранит…) нақтылау керек болса — ескертпеде.
- Материалы белгісіз нысан: кестеде «—», жоспарда штрихсыз. Бұл «материал енгізілмеген» мен «материал жоқ» екеуін ажыратпайды —
  1-кезеңдегі «—» / 0 қағидасы сияқты бос мән тек «белгісіз» дегенді білдіреді.

### 2.3. Құлпытастың типі (`subtype`)

С. Е. Ажигалидің жіктемесі бойынша; өріс тек `kind = kulpytas` болғанда көрінеді, басқа түрлерде бос. Өріс атауы жалпы
(`subtype`) — кейін басқа түрлерге де тип анықтамалығы керек болса, жаңа баған қосылмайды.

| Код | ҚАЗ | РУС |
|---|---|---|
| `block` | Аз өңделген блок | Слабообработанный блок |
| `classic` | Классикалық құлпытас | Классический кулпытас |
| `fert` | Стелоферт («Ф» пішінді) | Стелоферт (в виде «Ф») |
| `anthropo` | Антропоморфты құлпытас | Антропоморфный кулпытас |
| `unique` | Бірегей | Уникум |
| бос | — (типі анықталмаған) | — |

Экспликацияда «Түрі» бағанында жақшамен беріледі: «Құлпытас (классикалық)»; баптауларда (6.1) «Құлпытас типін көрсету»
қосулы/өшірулі (әдепкі — қосулы). Жоспардағы белгісі типке қарай өзгермейді.

### 2.4. Техникалық жай-күйі (`state`) — міндетті емес өріс

Паспорттың 9-тармағымен бірдей: `good` жақсы / хорошее, `fair` қанағаттанарлық / удовлетворительное, `poor` қанағаттанарлықсыз /
неудовлетворительное, `emergency` авариялық / аварийное, бос — көрсетілмеген. Нысан карточкасында әрдайым бар; экспликацияда бағаны пайдаланушының қалауымен көрсетіледі (6.1).

## 3. Деректер моделі (`plan_objects` және `plans` қабаттарына қосымша)

Барлық жаңа өріс **міндетті емес**; ескі жазбаларда жоқ болса — бос. Ескі файл жаңа нұсқада ашылады, Android қабатты оқымайды.

| Өріс | Түрі | Ескерту |
|---|---|---|
| `kind` | бар өріс | мәндер тізімі 2.1-ге дейін кеңейеді |
| `material` | мәтін (код) | 2.2; GeoPackage-те жеке баған (QGIS-те сүзу үшін) |
| `subtype` | мәтін (код) | 2.3; тек құлпытаста; GeoPackage-те жеке баған |
| `state` | мәтін (код) | 2.4 |
| `plans.expl` | объект (JSON, `props`-та) | экспликация баптаулары (6.1): `{ cols: [{ key, show, width }], row_h, font, short, place, zone_h }`; жоқ болса — әдепкі мәндер. `main/plans.js` → `cleanPlan()`-ға қосылуы міндетті |
| `shape = 'rect'` | бар өріс, жаңа мән | тіктөртбұрыш контур: `ax_a` — ұзындығы, `ax_b` — ені, `ax_az` — ұзын қабырғаның азимуты. Эллипс өрістері қайта пайдаланылады — жаңа баған керек емес. Сағанатам, қоршау, кесене, сандықтас үшін |

Іске асырғанда міндетті түрде: `main/plans.js` → `cleanObject()` (KINDS, SHAPES, жаңа өрістер), `main/gpkg.js` → `plan_objects.cols`
(`material`, `subtype`, `state`), `main/plan-geom.js` және `src/plan/geo.js` → тіктөртбұрыштың төбелері. `clean()` тізімде жоқ өрістерді тастап
жібереді — жаңа өріс сонда қосылмаса, сақтағанда жоғалады.

## 4. Жоспардағы көрініс

- **Контуры өлшенген нысан** — нақты пішіні мен масштабы сақталады (ТЗ 10-бөлім). Ішкі толтыру — материал штрихы, жиегі — түріне қарай:
  кесене — жуан тұтас (0,5 мм), сағанатам — қос сызық, қоршау — үзік сызық (ішіндегі нысандар көрінеді), қалғандары — жіңішке тұтас.
- **Контуры жоқ нысан** — 2.1-дегі векторлық белгі тұрақты өлшемде (≈ 4 мм), масштабқа тәуелсіз, тірек нүктесінің орнында.
- **Нөмір** — нысанның жанында (1-кезеңдегідей сүйреп жылжытуға болады). Қорғандардағы бөлшек белгі (биіктігі / диаметрі) тек
  `kurgan` түріне сақталады; қалған түрлерде тек нөмір — өлшемдер экспликацияда.
- **Түстер**: беттің негізі ақ-қара (көшірмеге, факсқа жарамды); қорғандардың 1-кезеңдегі қоңыр толтыруы өзгермейді.
- Барлық белгі мен штрих PDF-ке вектор түрінде түседі (SVG `<pattern>` → Chromium PDF).

## 5. «Шартты белгілер» блогы

- Тек **сызбада кездесетін** түрлер мен материалдар шығады (ТЗ 10-бөлім) — бос жолдар жоқ.
- Екі топ: «Нысан түрлері» (белгі + атауы), «Материалдар» (10 × 6 мм штрихталған тіктөртбұрыш + атауы).
- Құжат тілінде; белгілер анықтамалықтан алынады — жоспар мен блокта бір функциямен салынады (сәйкессіздік болмайды).

## 6. Экспликация кестесі

Бағандар (ені, мм; жазу 2,8–3 мм, жол биіктігі 5 мм):

| | № | Түрі / Тип | Материалы / Материал | Өлшемі, м / Размеры, м | Ескертпе / Примечание |
|---|---|---|---|---|---|
| Жоспар бетінде (жарты ені, 98 мм) | 7 | 19 | 24 | 21 | 27 |
| Жалғасы беттерінде (толық ені, 182 мм) | 10 | 36 | 36 | 30 | 70 |

Жарты енді кестеде ұзын атау тасымалданады (жол биіктігі өседі) не анықтамалықтағы қысқа атауы шығады
(«Күйдір. кірпіш»); қайсысы — іске асырғанда макетте тексеріледі.

- **№** жоспардағы нөмірмен сәйкес; жолдар нөмірдің табиғи ретімен (1, 2, …, 10, 1а дұрыс орында).
- **Өлшемдері** нысан деректерінен құрылады: шеңбер — «Ø 6», эллипс және тіктөртбұрыш — «6,2 × 4,0», биіктігі бар болса — «; h 1,2».
  Өлшенбеген — «—».
- **Ескертпе** — нысанның қысқа ескертпесі (құжат тілінде, жоқ болса — екінші тілдегісі; экспорт алдында ескертіледі).
- **Жай-күйі** (2.4) — бағаны әдепкіде өшірулі, пайдаланушы қосады (6.1).
- Тақырып жолы әр бетте қайталанады.

**Бетке орналастыру.** Жалпы жоспар бетінде сызба аймағы жоғарғы бөлікте, төменгі аймақта (≈ 70 мм) сол жақта — «Шартты белгілер»,
оң жақта — экспликацияның басы (≈ 12 жол). Сыймағаны «Экспликация (жалғасы)» беттерінде, әр бетте ≈ 48 жол. Жоспардың масштабы
сақталады: экспликация сызба аймағын кішірейтеді, бірақ масштабты автоматты таңдағанда ескеріледі (кішірейген аймаққа сыятын ең ірісі).
Біріктірілген PDF реті: жалпы жоспар → экспликацияның жалғасы → жеке жоспарлар.

Кестенің орнын пайдаланушы таңдайды (6.1): «жоспар бетінде басталсын» (әдепкі) не «бөлек бетте».

### 6.1. Экспликация баптаулары (пайдаланушы таңдайды)

Экспликацияның көрінісі қатаң бекітілмейді: «Алдын ала қарау» терезесінде **«Экспликация баптаулары»** бөлімі болады,
өзгеріс бірден бетте көрінеді. Баптаулар ескерткіштің жоспарымен бірге сақталады (`plans` жазбасы, 3-бөлім) — келесі
экспорттарда да, бағдарламаны қайта ашқанда да сол күйі. «Әдепкі күйге қайтару» батырмасы бар.

| Баптау | Мәндері | Әдепкі |
|---|---|---|
| Бағандарды көрсету | «№» мен «Түрі» — әрдайым; Материалы, Өлшемі, Жай-күйі, Ескертпе — әрқайсысы қосылады/өшіріледі | Жай-күйінен басқасы қосулы |
| Бағандардың реті | № әрдайым бірінші; қалғандарын ↑ ↓ арқылы ауыстыру | 6-бөлімдегі рет |
| Бағанның ені | әр баған үшін мм (не «авто») | авто: бет еніне мазмұнға қарай бөлінеді |
| Жол биіктігі | 4–12 мм, не «авто» (ұзын мәтін тасымалданып, жол өседі) | авто, ең азы 5 мм |
| Жазу өлшемі | 2,5–4 мм | 2,8 мм |
| Құлпытас типін көрсету | қосулы / өшірулі | қосулы |
| Атаулар | толық («Күйдірілген кірпіш») / қысқа («Күйдір. кірпіш») | толық, тасымалданады |
| Кестенің орны | жоспар бетінде басталады / әрдайым бөлек бетте | жоспар бетінде |
| Жоспар бетіндегі экспликация аймағының биіктігі | 40–120 мм | 70 мм |

Шектеулер (бет бұзылмауы үшін):
- Бағандардың жалпы ені беттің жұмыс енінен (жоспар бетінде ≈ 98 мм, жалғасы беттерінде ≈ 182 мм) асса — «авто» бағандар
  қысқарады; бәрі қолмен берілсе — ескерту шығады және ең кең баған сыйғанша кішірейеді.
- Жол биіктігі жазу өлшемінен кем болмайды (жол ≥ жазу × 1,5).
- Экспликация аймағы ұлғайса, сызба аймағы кішірейеді: автоматты масштаб соған қарай қайта таңдалады, қолмен таңдалған
  масштаб сыймаса — 1-кезеңдегідей ұсыныс шығады. Жоспардағы контурлар мен белгілер қиылмайды.
- «Шартты белгілер» блогы экспликация аймағының сол жағында қалады; кесте бөлек бетке шықса — блок жоспар бетінде қалады.

### 6.2. Қағаз өлшемі

Жоспардың барлық беті (жалпы жоспар, экспликацияның жалғасы, жеке жоспарлар) бір қағаз өлшемінде шығады: A5, A4, A3, A2, A1, A0
(тік не жатық) не өз өлшемі (ені мен биіктігі 100–3000 мм); әдепкі — A4 тік. Таңдау — «Алдын ала қарау» мен PDF терезесінде,
жоспармен бірге сақталады (`plans.paper`: `{ size, orient, w, h }`). Беттің аймақтары қағазға қарай есептеледі (рамка 7 мм,
жоғарғы 50 мм — тақырып пен солтүстік көрсеткісі, төменгі ≈ 25 мм — масштаб сызығы, экспликация беттің оң жартысында);
жазулардың өлшемі (мм) өзгермейді, масштаб 1:1 сақталады, үлкен қағазда автоматты масштаб ірілейді. Экспликация аймағының
биіктігі — 40–400 мм.

## 8. Шешімдер

Шешілгені (барлық сұрақ жабылды):
- **құлпытастың типі** — бөлек өріс `subtype`, Ажигали бойынша 5 тип (2.3);
- **техникалық жай-күй** — нысанның міндетті емес өрісі; экспликациядағы бағаны пайдаланушы өзі қосады;
- **жазу (эпитафия)** өрісі қосылмайды — қажет болса, ескертпеге жазылады;
- **экспликацияның көрінісі мен орны** — пайдаланушы баптайды: бағандар, реті, ені, жол биіктігі, жазу өлшемі, кестенің орны (6.1);
- «табиғи кірпіш» → **«Табиғи тас» / «Природный камень»** (код `stone`);
- **сандықтас, үштас, бестас** анықтамалыққа қосылды (`sandyktas`, `ushtas`, `bestas`).
