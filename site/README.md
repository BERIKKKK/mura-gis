# Mura GIS сайты

Статикалық сайт (HTML + CSS, сыртқы тәуелділіксіз): `index.html` — бағдарлама туралы, `developer.html` — жасақтаушы
туралы, `maps.html` — карталар жинағы (офлайн карталарды жүктеу бөлімінің дайындамасы).

Қарап шығу: `index.html` файлын браузерде ашыңыз. Жариялау: осы қалтаны кез келген статикалық хостингке
(мыс. GitHub Pages) жүктеу жеткілікті.
