# NIPD GeoJSON Exporter — Mura GIS үлгі плагині

«Қорғау аймағы → Нәтиже және экспорт → **NIPD GeoJSON**» әрекетін қосады.

* Экспортқа **тек ескерткіш аумағының полигоны** кіреді — қорғау аймағы, құрылыс салуды реттеу аймағы мен ландшафт аймағы кірмейді.
* Атрибуттар ескерткіш белгісінен (`mark_id` арқылы) және аймақ жазбасынан алынып, `config/nipd-schema.json` схемасы бойынша
  сәйкестендіріледі; өрістердің түрі, міндеттілігі, ұзындығы, рұқсат етілген мәндері тексеріледі. Схемаға сәйкес келмесе — файл сақталмайды.
* Геометрия тексеріледі (тұйықтық, өзін-өзі қиып өту, координаттар шегі); қажет болса EPSG:3857 не WGS 84 / UTM-ге түрлендіріледі.
* Экспорт тілі интерфейс тілінен тәуелсіз (баптау).

> **Маңызды.** `config/nipd-schema.json` — **мысал**, НИПД-ның ресми өрістер құрылымы емес. Порталдың нақты талаптарын алған соң
> файлды не плагин баптауларындағы «Өрістер схемасы (JSON)» өрісін соған сәйкес өзгертіңіз. Mura GIS ядросына НИПД құрылымы енгізілмейді.

Рұқсаттар: `geometry.read`, `attributes.read`, `files.export` (желі қажет емес).

Жинау: `node ../../tools/pack.mjs .` → `kz.mura.nipd-exporter-1.0.0.muraplug`. Тест: `node ../../tools/run.mjs . export`.
