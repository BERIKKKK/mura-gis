# NIPD GeoJSON Exporter — Mura GIS үлгі плагині

«Қорғау аймағы → Нәтиже және экспорт → **NIPD GeoJSON**» әрекетін қосады. Қорғау аймақтарынан **тек ескерткіш аумағының
полигонын** алып (қорғау, құрылыс салуды реттеу және ландшафт аймақтары кірмейді), НИПД порталының атрибуттар кестесіне
сәйкестендіреді және бір GeoJSON файлын береді.

## Шығыс құрылымы (НИПД үлгісі бойынша)

```json
{ "type": "FeatureCollection", "name": "экспорт arm monuments …",
  "crs": { "type": "name", "properties": { "name": "urn:ogc:def:crs:EPSG::10941" } },
  "features": [ { "type": "Feature", "id": "<Mura id>", "geometry": { "type": "Polygon", … },
    "properties": { "name": "Могильник Акжар-ІІ", "category_level": "Местного значения", "type": "Археологический",
      "monument_kind": "Могильник", "inclusion_date": "2020-08-18T00:00:00Z", "included_by_authority": "Акимат Актюбинской области",
      "responsible_organization": "Управление культуры, архивов и документации Актюбинской области",
      "website_link": "https://zan.gov.kz/client/#!/doc/145648/kaz" } } ] }
```

| Өріс | Қайдан |
|---|---|
| `name` | ескерткіш белгісінің атауы (орысшасы; жоқ болса қазақшасы), белгі жоқ болса — аймақ атауы |
| `category_level` | белгінің санаты: intl / rep / local → «Международного / Республиканского / Местного значения» |
| `type` | белгінің түрі: archeo → «Археологический» (қалған мәндер — болжам, `config/nipd-schema.json`-да тексеріңіз) |
| `monument_kind` | атаудан анықталады (могильник / қорым → «Могильник», курган / қорған → «Курган», поселение, городище…); анықталмаса — тексеру терезесінде енгізіледі және ескерткіш бойынша есте қалады |
| `inclusion_date`, `included_by_authority`, `responsible_organization`, `website_link` | **ортақ өрістер** — бір рет енгізіледі, барлық нысанға жазылады, облыс бойынша есте сақталады |

* Экспорт: ағымдағы аймақ не **барлық сақталған қорғау аймақтары** — бір файлға. Қатесі бар нысандар тізімде көрсетіледі;
  «Тек дұрыстарын сақтау» мүмкін.
* Координаттар: Mura GIS-тің WGS 84 градустары түрлендірусіз жазылып, `crs` белгісі **QazTRF-23 (EPSG:10941)** қойылады —
  QazTRF-23 геодезиялық жүйесі (GRS 1980, ITRF негізінде) мен WGS 84 айырмасы сантиметр деңгейінде. Басқа жүйе керек болса — баптаудағы «Координаттар жүйесі».
* Mura GIS id-і әр нысанның `Feature.id`-іне жазылады (атрибуттарға кірмейді); баптаудан өшіруге болады.
* Құрылымды өзгерту — `config/nipd-schema.json` не плагин баптауындағы «Өрістер схемасы (JSON)».

Рұқсаттар: `geometry.read`, `attributes.read`, `files.export` (желі қажет емес).
Жинау: `node ../../tools/pack.mjs .`; тест: `node ../../tools/run.mjs . export`. Лицензия: MIT.
