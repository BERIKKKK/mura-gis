# Атау сәйкестендіргіш (Mura GIS үлгі плагині)

Ескерткіштер тізімін бекіткен қаулыны (мыс. «… жергілікті маңызы бар тарих және мәдениет ескерткіштерінің мемлекеттік
тізімі») өзі талдап, белгі қойғанда атауды ресми тізіммен сәйкестендіреді. Mura GIS 2.4.4+ (`files.import`, `mark.suggest`, `zone.suggest`).

## Пайдалану

1. **⋯ → Қаулылар (атау сәйкестендіру)… → Қаулы жүктеу…** — бір қаулының қазақша және орысша файлдарын бірге таңдаңыз
   (DOCX не мәтіні бар PDF, кемінде 2 файл; adilet.zan.kz-тен жүктелген DOCX/PDF жарайды). Бірнеше қаулыны бірге
   таңдауға болады — файлдар қаулының тіркеу нөмірі бойынша топталады.
2. Тексеру терезесінде қаулы, тілдер, ескерткіш және аудан саны көрсетіледі. Құжатта неше ескерткіш екенін білсеңіз,
   енгізіңіз (құжаттың өз қорытындысы болса, ол алдын ала толтырылады) — сан сәйкес келмесе, ескертіледі.
3. Белгі қойғанда не атауын жаза бастағанда («Қараб…», «Карабутак-3») белгі терезесінде **«Плагин ұсынысы»** шығады.
   Таңдасаңыз, атауы, мерзімі, орналасқан жері (екі тілде), түрі, санаты, ауданы толтырылады — тексеріп, «Сақтау» басыңыз.
   Атауы әлі жазылмаған не тізімде табылмаған болса, өрістің астында кеңес шығады.
   Қорғау аймағында да солай: шекараны белгілеп, «Аяқтау» басқанда мәліметтер терезесінде «Плагин ұсынысы» шығады
   (орны — шекараның ортасы бойынша).
4. **Өшіру** — таңдалған не барлық қаулының тізімі плагиннен толық жойылады. Белгілердің өзі өзгермейді.

## Не сақталады

Файлдың өзі сақталмайды — тек тізім: №, аудан, атауы, мерзімі, түрі, орналасқан жері (екі тілде) және қаулының
мәліметтері (нөмірі, күні, тіркеу нөмірі, редакциясы). Тізім жоба файлынан бөлек, плагиннің жадында (`mura.storage`, ≤ 5 МБ;
863 ескерткіштік тізім ≈ 0,2 МБ).

## Қалай талданады

* `lib/files.js` — DOCX (ZIP + `word/document.xml`, кестелер, біріктірілген ұяшықтар; өшірілген түзетулер алынбайды) және
  PDF (xref, Flate, Type0/ToUnicode қаріптері, мәтіннің беттегі орны). Сыртқы кітапхана жоқ. Сканерленген (суреттен тұратын)
  PDF оқылмайды — бұл туралы хабар шығады.
* `lib/decree.js` — тілі (қазақ әріптері бойынша), қаулының мәліметтері, «№ | Атауы | Түрі | Орналасқан жері» кестесі
  (PDF-те кесте бағандары координаттан қалпына келтіріледі, әр беттегі сайт баннері алынады, сөз тасымалы біріктіріледі),
  аудан жолдары, атау мен мерзімнің бөлінуі, қорытынды кесте («всего / барлығы»).
* `lib/match.js` — атауды қалыптау (рим цифры → сан, қ/к, ұ/у, ә/а…, жалпы сөздер — бейіті, қорғаны, могильник…), нөмір
  бөлек тексеріледі (Қарабұтақ-ІІІ ≠ Қарабұтақ-IV), аудан сәйкестігі; «Қос-Естек ауылынан оңтүстік батысқа қарай 12 шақырым
  700 метр» сипаттамасы бойынша ауыл «Өзге нысандарда» болса — ескерткіштің шамамен орны мен белгіге дейінгі қашықтық.

## Рұқсаттар

`files.import` — сіз таңдаған файлдарды оқу; `attributes.read` — белгі терезесіндегі атау, аудан, облыс және «Өзге
нысандардағы» ауыл атаулары; `geometry.read` — белгінің және ауылдардың координатасы (шамамен орын үшін).
Желіге шықпайды, жоба деректерін өзгертпейді.

## Тексеру

`node scripts/test-plugins.mjs` (талдау, сәйкестендіру, SDK арқылы жүктеу / өшіру / ұсыныс) және
`npm run smoke:plugins` (Electron: каталогтан орнату, екі файл, белгі терезесіндегі ұсыныс).
